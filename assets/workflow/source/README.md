# Workflow practice pack

Start with starter/. It deliberately includes fixed-width overflow, string concatenation instead of numeric addition, and a wrong JSON URL. solution/ demonstrates the repairs. Keep this extracted pack separate from other repositories.

With a supported Node.js runtime installed, open a terminal in this folder and run `node serve.mjs starter`. Open the printed URL. Stop with Ctrl+C. Use `node serve.mjs solution` to compare after attempting the lessons, or add an unused port as a third argument. No npm install is needed for this server.

Open tests.html through the server. Starter failures are intentional; the solution has nine passing checks. Templates are blank evidence records, not claims of passing. The course explains Git setup, browser investigation, and release steps. For Git exercises initialise only starter/, not the parent pack and not an existing project. No real credentials or cloud configuration are included.
