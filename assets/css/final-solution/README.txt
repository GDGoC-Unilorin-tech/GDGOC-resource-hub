Final challenge: Build and audit your styled portfolio

This is a suggested implementation, not a required visual design. Attempt the project before comparing. The sample retains a fictional HTML portfolio and adds a shared stylesheet. It does not send messages or save progress.

Extract the ZIP. Open index.html for layout practice. To test video text tracks, serve the extracted folder through your editor's preview server or run py -m http.server 8000 (Windows) / python3 -m http.server 8000 (macOS/Linux) if Python is installed, then visit http://localhost:8000. Stop the server with Ctrl+C.

Read styles.css and compare it to the stage requirements. Source order and component names are intentional. Beginner supplies readable basic styling; Intermediate adds responsive layout and tokens; Advanced and Final add layers, local component queries, subgrid, system themes, reduced-motion support, and print rules. CSS cannot deliver messages or implement persistent application state.

The final example integrates the Advanced design; it is not a different framework. Your final milestone is your own content, decisions, evidence, and refinements. Use REVIEW.md for actual observations; none of its rows are pre-marked passed. The supplied HTML media and diagrams are local practice assets.
