CSS practice pack

Use portfolio/ as a starting point if you do not have your own completed HTML portfolio. It contains fictional content and local media. Adapt it to your own work while keeping the semantic HTML.

Each lessons/ folder is a separate runnable example, with index.html, styles.css, and a separate suggested-solution.css. Keep each example isolated. The examples are not a single stylesheet to concatenate. Lessons i09 and a09 intentionally start with defects; use their solutions after reproducing them.

Open index.html directly for CSS practice. For portfolio video text-track tests, serve the extracted folder through your editor's local preview server, or run py -m http.server 8000 on Windows / python3 -m http.server 8000 on macOS or Linux if Python is installed. Visit http://localhost:8000 and stop with Ctrl+C.

No package installation, API key, external font, or paid service is needed. Forms are local GET demonstrations, not real message delivery; use fictional data. Copy the portfolio into a new folder for each stage and keep an audit record.
