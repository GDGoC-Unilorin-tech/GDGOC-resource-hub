Use transitions with reduced-motion support

Open index.html to run the worked example. Edit styles.css to attempt the challenge below. Compare with suggested-solution.css only after trying. To test the solution, replace styles.css with its contents; the HTML continues to link to styles.css.

Challenge: Use a 120ms transition and a 1px upward movement. Preserve no movement under reduced motion and retain the keyboard outline.

Hint: Keep transform and transition inside the no-preference query, not the focus outline.

Criteria:
- Hover and keyboard focus receive deliberate feedback.
- Reduced motion removes the movement but preserves focus and navigation.
- Only transform is transitioned.
