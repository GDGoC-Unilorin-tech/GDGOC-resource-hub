Adapt layouts with media queries

Open index.html to run the worked example. Edit styles.css to attempt the challenge below. Compare with suggested-solution.css only after trying. To test the solution, replace styles.css with its contents; the HTML continues to link to styles.css.

Challenge: Use equal columns starting at 50rem, retain a one-column base, and increase the gap to 1.5rem at the breakpoint.

Hint: Put the wider grid-template-columns and gap in the same min-width query.

Criteria:
- The base layout works without a matching query.
- The two-column override begins at the intended breakpoint.
- Both columns remain readable with enlarged text.
