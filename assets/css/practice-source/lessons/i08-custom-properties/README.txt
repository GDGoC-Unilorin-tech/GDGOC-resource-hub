Reuse design values with custom properties

Open index.html to run the worked example. Edit styles.css to attempt the challenge below. Compare with suggested-solution.css only after trying. To test the solution, replace styles.css with its contents; the HTML continues to link to styles.css.

Challenge: Set shared card padding to 1.5rem and make the featured card purple (#6a1b9a), without copying the entire .card rule.

Hint: Override the custom property on .featured, not the descendant heading colour.

Criteria:
- Both cards share the new padding.
- Only the featured card uses the purple accent.
- No duplicated card rule is needed for the variation.
