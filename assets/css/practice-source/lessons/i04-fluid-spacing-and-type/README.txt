Use fluid sizing with limits

Open index.html to run the worked example. Edit styles.css to attempt the challenge below. Compare with suggested-solution.css only after trying. To test the solution, replace styles.css with its contents; the HTML continues to link to styles.css.

Challenge: Make the heading range from 1.75rem to 2.75rem with preferred 1.25rem + 2vw. Keep fluid padding and wrapping.

Hint: The first and third clamp arguments are bounds, not breakpoints.

Criteria:
- Measured font sizes stay within the intended bounds.
- The long heading wraps at narrow widths.
- The page remains usable at 200% zoom.
