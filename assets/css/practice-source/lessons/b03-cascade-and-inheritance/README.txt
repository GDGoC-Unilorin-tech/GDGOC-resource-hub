Understand the cascade and inheritance

Open index.html to run the worked example. Edit styles.css to attempt the challenge below. Compare with suggested-solution.css only after trying. To test the solution, replace styles.css with its contents; the HTML continues to link to styles.css.

Challenge: Make the intro green and ordinary paragraphs blue, with no duplicate .intro colour rule and no !important. Explain which property both paragraphs inherit.

Hint: Remove the accidental override instead of adding a third rule.

Criteria:
- Computed colours match the requested result.
- There is one intentional .intro colour rule.
- You can identify the inherited font family.
