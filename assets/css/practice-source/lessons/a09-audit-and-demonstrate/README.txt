Audit and demonstrate a styled website

Open index.html to run the worked example. Edit styles.css to attempt the challenge below. Compare with suggested-solution.css only after trying. To test the solution, replace styles.css with its contents; the HTML continues to link to styles.css.

Challenge: Repair width, text wrapping, and keyboard focus. Create an audit table for your entire portfolio, with a row for every tested page and state. Include at least one repair and two honest limitations.

Hint: Use a flexible box and explicit focus-visible styling. Do not record template expectations as if you observed them.

Criteria:
- Both deliberate defects have a saved repair and retest.
- Every portfolio page is covered in the audit record.
- Untested conditions are clearly distinguished from passing results.
