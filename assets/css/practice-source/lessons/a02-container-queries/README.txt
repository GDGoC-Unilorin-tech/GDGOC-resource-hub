Open index.html to run the worked example. Edit styles.css to attempt the challenge below. Compare with suggested-solution.css only after trying. To test the solution, replace styles.css with its contents; the HTML continues to link to styles.css.

Challenge: Change the component breakpoint to 32rem and use equal columns when it matches. Keep the wrapper named and the base single-column.

Hint: The width condition belongs to profile-slot; the layout declarations target its .profile descendant.

Criteria:
- A narrow slot stays single-column inside a wide viewport.
- A sufficiently wide slot changes to equal columns.
- Disabling the enhancement leaves usable content.
