Maintain styles and support printing

Open index.html to run the worked example. Edit styles.css to attempt the challenge below. Compare with suggested-solution.css only after trying. To test the solution, replace styles.css with its contents; the HTML continues to link to styles.css.

Challenge: Keep the print rules, add a black 1px card border in print, and make every link print with black underlined text. Record whether all report content fits and is readable.

Hint: Put the print-only changes in the existing @media print block, leaving screen presentation separate.

Criteria:
- Screen navigation is preserved.
- Print output keeps the report readable and removes only nonessential navigation.
- Any optimisation claim is supported by a recorded comparison.
