Select elements with reusable classes

Open index.html to run the worked example. Edit styles.css to attempt the challenge below. Compare with suggested-solution.css only after trying. To test the solution, replace styles.css with its contents; the HTML continues to link to styles.css.

Challenge: Give every card 16px of inner spacing, make its h2 dark green, and leave the outside paragraph unchanged. Keep the intro enlarged.

Hint: Use .card h2 to select headings inside cards. Padding supplies inner spacing; the box-model lesson explains it further.

Criteria:
- Both original and duplicated cards share styling.
- Only headings inside cards receive the green rule.
- The outside paragraph retains its default colour.
