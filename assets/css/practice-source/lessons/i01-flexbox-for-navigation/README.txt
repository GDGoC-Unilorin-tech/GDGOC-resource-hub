Arrange navigation with Flexbox

Open index.html to run the worked example. Edit styles.css to attempt the challenge below. Compare with suggested-solution.css only after trying. To test the solution, replace styles.css with its contents; the HTML continues to link to styles.css.

Challenge: Keep wrapping navigation, set gap to 1rem, and give each link a visible 1px border. Do not reorder the links or reduce their labels.

Hint: Flexbox belongs on the parent; spacing and borders can then be applied to the links.

Criteria:
- All links remain visible at narrow widths.
- Gap is 1rem without margin workarounds.
- Keyboard order agrees with the HTML reading order.
