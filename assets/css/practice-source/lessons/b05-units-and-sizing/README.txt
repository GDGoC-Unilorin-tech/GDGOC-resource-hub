Choose units and flexible widths

Open index.html to run the worked example. Edit styles.css to attempt the challenge below. Compare with suggested-solution.css only after trying. To test the solution, replace styles.css with its contents; the HTML continues to link to styles.css.

Challenge: Change the reading column to 92% width with a 40rem maximum and 1.5rem padding. Keep it centred and allow any amount of text.

Hint: Do not add height or overflow:hidden to make the sample look tidy.

Criteria:
- The column shrinks with its parent.
- It remains centred and stops at 40rem.
- Longer text stays visible without a fixed height.
