Build light and dark themes with tokens

Open index.html to run the worked example. Edit styles.css to attempt the challenge below. Compare with suggested-solution.css only after trying. To test the solution, replace styles.css with its contents; the HTML continues to link to styles.css.

Challenge: Add --panel as #f8fafd in light mode and #303134 in dark mode, then use it on .panel. Keep all existing states usable.

Hint: Override the new token inside the same preference query instead of duplicating the whole panel rule.

Criteria:
- Both preference settings use the intended panel colour.
- Text, links, fields, and focus indicators remain visible.
- Contrast results are recorded for both themes.
