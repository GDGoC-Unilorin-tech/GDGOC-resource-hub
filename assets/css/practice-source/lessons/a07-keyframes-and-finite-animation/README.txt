Create a restrained keyframe animation

Open index.html to run the worked example. Edit styles.css to attempt the challenge below. Compare with suggested-solution.css only after trying. To test the solution, replace styles.css with its contents; the HTML continues to link to styles.css.

Challenge: Reduce the starting offset to 4px and duration to 180ms. Keep one iteration, visible base content, and the reduced-motion protection.

Hint: Change the keyframe offset and animation duration; do not add opacity:0 to the base style.

Criteria:
- The animation runs once and ends in the readable base state.
- Reduced motion shows the complete message without movement.
- There is no flashing or ongoing decorative animation.
