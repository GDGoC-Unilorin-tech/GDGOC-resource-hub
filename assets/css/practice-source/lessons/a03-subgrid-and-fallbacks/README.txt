Align card content with subgrid

Open index.html to run the worked example. Edit styles.css to attempt the challenge below. Compare with suggested-solution.css only after trying. To test the solution, replace styles.css with its contents; the HTML continues to link to styles.css.

Challenge: Increase the gap to 1.5rem and give card headings margin:0. Keep both the fallback and the subgrid enhancement. Add a third card with a longer description.

Hint: The parent owns the gap. Subgrid must share tracks that the card spans.

Criteria:
- Cards remain readable with the enhancement disabled.
- Supported subgrid rows align corresponding card content.
- New content does not require fixed card heights.
