Challenge: Add a 4px solid #174ea6 left border to the notice. Keep its explicit status text, readable colours, and the underlined link. Record contrast for both text pairs.

Hint: A border can reinforce a message, but it must not replace the words that explain it.

Criteria:
- Text/background pairs have recorded contrast checks.
- The notice has both wording and a visual cue.
- The link is identifiable without relying only on colour.
