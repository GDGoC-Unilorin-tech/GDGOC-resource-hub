Open index.html to run the worked example. Edit styles.css to attempt the challenge below. Compare with suggested-solution.css only after trying. To test the solution, replace styles.css with its contents; the HTML continues to link to styles.css.

Challenge: Make the badge a block link with 1rem padding and keep the long text wrapping. Do not hide any content or add a horizontal scrollbar to the entire page.

Hint: Change display on the badge; solve the long text with wrapping rather than hiding overflow.

Criteria:
- The badge occupies its own line and stays keyboard-operable.
- The long identifier wraps inside the panel.
- No content or focus outline is clipped.
