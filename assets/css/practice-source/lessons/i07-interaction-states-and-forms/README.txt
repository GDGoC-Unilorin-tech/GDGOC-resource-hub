Style focus, links, and form controls

Open index.html to run the worked example. Edit styles.css to attempt the challenge below. Compare with suggested-solution.css only after trying. To test the solution, replace styles.css with its contents; the HTML continues to link to styles.css.

Challenge: Add a 1px #747775 border to the text fields and a 0.5rem radius. Make the submit button’s hover and focus-visible background match, while keeping its visible outline.

Hint: Use a selector list for the two button states; keep the global focus-visible rule.

Criteria:
- Every focusable control has a visible keyboard focus state.
- Labels and native validation still work.
- Textarea resizing and readable control text remain available.
