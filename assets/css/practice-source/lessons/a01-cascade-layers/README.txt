Organise the cascade with layers

Open index.html to run the worked example. Edit styles.css to attempt the challenge below. Compare with suggested-solution.css only after trying. To test the solution, replace styles.css with its contents; the HTML continues to link to styles.css.

Challenge: Keep the three layers, make the utility override purple (#6a1b9a), and add a 1px border in the components layer. Do not use !important or an unlayered colour rule.

Hint: Put structural component styling in components and the intentional variation in utilities.

Criteria:
- The declared layer order is explicit.
- The purple utility wins without increased specificity.
- The card keeps its component padding and border.
