Separate decoration from content

Open index.html to run the worked example. Edit styles.css to attempt the challenge below. Compare with suggested-solution.css only after trying. To test the solution, replace styles.css with its contents; the HTML continues to link to styles.css.

Challenge: Use a white background, a 2px border, and a 4rem decorative accent. Remove the shadow, keeping all meaningful text in HTML.

Hint: Change the existing declarations and remove box-shadow rather than adding another overriding card rule.

Criteria:
- Decoration can be disabled without losing content.
- Border, radius, and background meet the brief.
- No essential words are generated with content.
