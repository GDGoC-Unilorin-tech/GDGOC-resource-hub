Use the box model and predictable spacing

Open index.html to run the worked example. Edit styles.css to attempt the challenge below. Compare with suggested-solution.css only after trying. To test the solution, replace styles.css with its contents; the HTML continues to link to styles.css.

Challenge: Make the card’s border box 300px wide, padding 16px, border 2px, and outside vertical margin 24px. Keep the HTML unchanged.

Hint: With border-box, subtract both paddings and borders from the declared width to predict content width.

Criteria:
- The border box measures 300px.
- The content width measures 264px.
- Spacing comes from CSS, not empty paragraphs or br elements.
