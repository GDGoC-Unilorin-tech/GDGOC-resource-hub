Build readable typography

Open index.html to run the worked example. Edit styles.css to attempt the challenge below. Compare with suggested-solution.css only after trying. To test the solution, replace styles.css with its contents; the HTML continues to link to styles.css.

Challenge: Set h2 to 1.5rem with 1.3 line height, retain the h1 styling, and limit the prose to 60ch. Keep visible link underlines.

Hint: Use a heading selector and a prose container; avoid sizing each individual paragraph separately.

Criteria:
- Body text uses a readable system font and line height.
- Headings remain semantically ordered.
- Text and links remain readable at 200% zoom.
