Use logical properties for adaptable layouts

Open index.html to run the worked example. Edit styles.css to attempt the challenge below. Compare with suggested-solution.css only after trying. To test the solution, replace styles.css with its contents; the HTML continues to link to styles.css.

Challenge: Make the accent 6px wide and use 2rem inline padding. Keep all spacing and sizing declarations logical. Test both direction settings.

Hint: Change border-inline-start and padding-inline; do not add a separate border-right rule.

Criteria:
- The accent follows the inline start in both directions.
- No physical left/right overrides are needed.
- The note remains readable when its content wraps.
