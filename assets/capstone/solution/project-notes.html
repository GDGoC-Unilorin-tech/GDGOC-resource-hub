Form boundaries

The practice form uses GET to navigate to a static page. It does not deliver messages; fictional values appear in the URL.

Real messages need a receiving service with server-side validation, appropriate access and abuse controls, and delivery or storage logic. POST does not encrypt a request; HTTPS protects transport.

A real file upload would normally use POST with multipart/form-data. File selection hints do not validate content; the service must validate and handle uploaded files safely.

Image choices and review evidence

The home image offers 480- and 960-pixel candidates. Its display width is capped at 480 pixels and shrinks with the page on narrow screens. The sizes attribute describes that slot. It is needed immediately, so it is not lazy-loaded.

Use REVIEW.md to record your own checks, selected image resources, defects, repairs, and limitations. This sample does not certify your work.
