# Frontend capstone assets

solution/ is an independently maintained snapshot of the CSS final portfolio with the JavaScript final explorer integrated into projects.html. Keep original course assets unchanged. Regenerate frontend-capstone-solution.zip with `python assets/capstone/build_archives.py` after edits. The archive uses public/ for deployable files; README.md and REVIEW.md remain at its root. Source suffixes prevent Mintlify from treating example CSS/JS as global site assets.
