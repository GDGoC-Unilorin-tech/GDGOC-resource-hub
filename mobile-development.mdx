</Tip>

## How to use these resources

<Tip>
  Start with official docs. Follow one video course at a time. Build alongside every lesson. Finish a project before starting a new course.
</Tip>

<Warning>
  Copying code without understanding it slows you down. Rebuild each project from scratch once, without the video.
</Warning>

## Common mistakes

<AccordionGroup>
  <Accordion title="Learning Android and Flutter at the same time">
    Pick one track for at least 3 months. The second one is much faster afterwards.
  </Accordion>
  <Accordion title="Skipping language basics">
    Weak Kotlin or Dart fundamentals make every framework concept harder.
  </Accordion>
  <Accordion title="Never publishing anything">
    Put at least one app on GitHub with a clear README. Publish to the Play Store if you can.
  </Accordion>
</AccordionGroup>
