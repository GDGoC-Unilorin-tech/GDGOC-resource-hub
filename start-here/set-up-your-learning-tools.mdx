## Prepare your workspace

For the first web lessons you need a computer, browser, and plain-text editor. A browser displays pages; an editor lets you write their files. A word processor is not a plain-text editor.

1. Create a folder called hub-practice somewhere you can find it.
2. Open that folder in your editor.
3. Create a file called notes.txt and write what you want to learn.
4. Save, close, and reopen it.

Keep practice tasks in separate folders. Save changes before checking results in your browser. Course overviews will explain additional tools. HTML lessons will show you how to create an HTML file and open it in a browser; no cloud account or framework is needed.
