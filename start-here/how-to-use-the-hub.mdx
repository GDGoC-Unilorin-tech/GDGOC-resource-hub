## Find your starting point

A learning path is a broad area such as Web Development. A track groups related skills, such as Frontend Development. A skill course focuses on one skill, such as HTML. Each course contains levels and individual topic lessons.

1. [Choose a path](/start-here/choose-a-learning-path).
2. [Prepare your tools](/start-here/set-up-your-learning-tools).
3. Read a course overview and check its prerequisites.

## Work through a course

Courses will guide you through Beginner, Intermediate, Advanced, and a Final building challenge. Each topic will include objectives, prerequisites, explanations, code examples, and a practice challenge with concrete requirements, expected outcomes, a completion checklist, optional hints, and a separate suggested solution. Attempt challenges before opening solutions. Each level ends with a project; the final challenge combines skills across the course.

Use completion criteria to assess readiness before moving on. Checklists are self-assessment; saved progress, automatic code assessment, and stage locking are not implemented.
