## Your roadmap

1. **HTML:** Structure content and connect pages.
2. **CSS:** Style that content and create responsive layouts.
3. **JavaScript:** Add useful behaviour and interaction.
4. **Capstone:** Plan, build, test, demonstrate, and deploy a complete website.
5. **Contribute:** Apply for a reviewed starter task with the technical team.

No coding experience is required to begin HTML. Learn HTML before CSS, and HTML plus basic CSS before JavaScript. Frameworks follow the core foundations. Learn Git early, use DevTools while practising, and study testing and deployment as your projects grow.
