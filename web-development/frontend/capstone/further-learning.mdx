Use these references after attempting the capstone, or to resolve a specific tooling problem.

| Need | Google resource |
| --- | --- |
| HTML reference learning | [web.dev Learn HTML](https://web.dev/learn/html) |

| JavaScript foundations | [web.dev Learn JavaScript](https://web.dev/learn/javascript) |
| Accessibility review | [web.dev Learn Accessibility](https://web.dev/learn/accessibility) |
| Inspect and debug | [Chrome DevTools documentation](https://developer.chrome.com/docs/devtools) |
| CLI installation and authentication | [Firebase CLI reference](https://firebase.google.com/docs/cli) |
| Hosting setup | [Firebase Hosting quickstart](https://firebase.google.com/docs/hosting/quickstart) |
| Local, preview, and live releases | [Firebase test, preview, and deploy](https://firebase.google.com/docs/hosting/test-preview-deploy) |
| Current allowances and costs | [Hosting usage and pricing](https://firebase.google.com/docs/hosting/usage-quotas-pricing) |

Keep your own review record. Completing these readings does not replace demonstrating your project.
