## Learning scope

Descriptive links; language and heading review; image alternatives; keyboard checks; skip links; native HTML before ARIA.

## Practice challenge

Add a skip link and improve a supplied page with vague links and missing image alternatives.

## Completion criteria

Skip link reaches main content; links are understandable; native interactive controls work with the keyboard.

## Content to develop

- Step-by-step explanation and code examples.
- Optional hints.
- Separately revealed suggested solution with explanation.
