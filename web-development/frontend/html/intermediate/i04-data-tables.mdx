## What you will learn

- Represent tabular data.
- Associate simple headers with cells.
- Use captions and row groups.

## Tables describe relationships in data

Use `table` when row and column relationships matter. Do not use tables to position a page's header or sidebar.

`tr` is a row. `th` is a header cell and `td` is a data cell. `caption` names the table. `thead` and `tbody` group header and body rows; they do not replace header associations.

For a simple table, `scope="col"` identifies a column header and `scope="row"` a row header. Keep the grid consistent. More complex spanning tables need more careful associations, so this course starts with a simple grid.

## Worked example

```html
<table>
  <caption>My weekly HTML practice</caption>
  <thead>
    <tr><th scope="col">Day</th><th scope="col">Topic</th></tr>
  </thead>
  <tbody>
    <tr><th scope="row">Monday</th><td>Headings</td></tr>
    <tr><th scope="row">Wednesday</th><td>Links</td></tr>
  </tbody>
</table>
```

The table may have no visible borders without CSS. Its semantics and data relationships still exist.

<Note>A bold-looking td is not a substitute for th.</Note>

## Try it and observe

### Read one data cell in context

Choose the Links cell in the example. Its row header is Wednesday and its column header is Topic. Identify both relationships in the source. Add a third Task column and check that every body row now has three cells. A missing cell can make later data appear under the wrong heading.

## Practice challenge

Build a three-row study schedule with Day, Topic, and Practice task columns. Add a caption, column headers, and row headers for the days.

Attempt the task first. Save your source and inspect the result in your browser. Record what you expected and what you observed.

<Accordion title="Need a hint?">
Count columns in the header and in each row. Day names can be row headers.
</Accordion>

## Completion checklist

- [ ] Caption explains the table.
- [ ] Column and row headers use appropriate scope.
- [ ] Each body row contains three cells.
- [ ] The table is for data, not layout.

<Accordion title="View a suggested solution">

```html
<table>
  <caption>Study schedule</caption>
  <thead><tr><th scope="col">Day</th><th scope="col">Topic</th><th scope="col">Task</th></tr></thead>
  <tbody>
    <tr><th scope="row">Monday</th><td>Text</td><td>Write a profile</td></tr>
    <tr><th scope="row">Tuesday</th><td>Links</td><td>Connect pages</td></tr>
    <tr><th scope="row">Friday</th><td>Review</td><td>Check paths</td></tr>
  </tbody>
</table>
```

This implementation follows the requirements above. Compare it with your own attempt against each checklist item. Your wording and other valid choices may differ. Explain one decision you made and revise any unmet criterion.

</Accordion>

## Check your understanding

What are the different jobs of `caption`, `th`, and `thead`?

Write your answer before opening the explanation.

<Accordion title="Check your answer">

Caption names the whole table. A th cell identifies a header for related data, with scope clarifying row or column in this simple grid. Thead groups header rows; it does not make ordinary td cells into headers.
