## Learning scope

`audio`, `video`, `source`, `track`, native controls, fallback information, captions, and transcripts.

## Practice challenge

Add a supplied short video with controls, a supplied caption file, and a transcript.

## Completion criteria

Media plays using native controls; caption track loads; transcript is available; autoplay is not required.

## Content to develop

- Step-by-step explanation and code examples.
- Optional hints.
- Separately revealed suggested solution with explanation.
