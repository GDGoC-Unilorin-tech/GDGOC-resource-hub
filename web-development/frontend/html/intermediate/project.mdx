## Project brief

Extend your Beginner portfolio instead of starting a new site. Retain the home and about pages and add projects.html, learning-log.html, and contact.html.

## Requirements and completion checklist

- [ ] Use meaningful header, nav, main, and footer regions on each page.
- [ ] Provide working navigation and skip links across the site.
- [ ] Describe your projects using logical headings and appropriate semantic elements.
- [ ] Add a learning-log table with caption, headers, and appropriate scope.
- [ ] Include a machine-readable date, an attributed quotation, and a displayed code snippet.
- [ ] Build a labelled, grouped practice contact form with appropriate input types, instructions, help text, and browser validation.
- [ ] State clearly that the practice form does not send or store messages.
- [ ] Include the supplied silent video with native controls, timed visual descriptions, and a transcript, or equivalent permitted media with appropriate captions.
- [ ] Test keyboard navigation, links, media, and fictional valid/invalid form entries.

## Plan and build

1. Back up your previous milestone before editing.
2. Map each requirement to a page and identify the assets needed.
3. Implement one requirement at a time using the related lessons.
4. Test in a browser after each change.
5. Record evidence and revise unmet criteria.

Use the supplied practice pack for images and the silent video with its timed visual descriptions and transcript. You may substitute your own permitted media with equivalent alternatives. Image variants and their dimensions are supplied; no image editor is required.

<Accordion title="Hints">
Start with the existing folder structure. Check paths from each page, keep IDs unique, and choose elements by meaning. Test with fictional data. Revisit the relevant module checkpoint when you encounter a problem.
</Accordion>

## Demonstrate and review

Keep the source files, local assets, a page map, and a short audit report. Demonstrate the required features and explain your decisions. For each checklist item record **Met**, **Needs revision**, or **Not yet attempted**, with evidence. A reviewer can add feedback separately; self-assessment is not automatic verification.





## Project materials

[Download the local practice assets](/assets/html/html-practice-assets.zip). Copy the images folder and, for later stages, the media folder into your project. Asset names and dimensions are listed in the pack README.

For the Intermediate and later milestones, use five main pages: index.html, about.html, projects.html, learning-log.html, and contact.html. A practice-result.html destination explains that no message is sent or stored. Optional supporting notes may have additional pages.
