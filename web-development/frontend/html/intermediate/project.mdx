> Authoring draft: this page defines curriculum scope. Full teaching content and solutions are pending.

Build three connected pages: an event overview, a schedule, and a registration form.

**Requirements and completion checklist**

- Pages use meaningful semantic regions and logical headings.
- Navigation and a skip link work with a keyboard.
- Schedule uses a captioned table with appropriate headers.
- Registration form contains labelled fields, grouped choices, help text, and suitable browser validation.
- Event dates use appropriate `time` markup.
- Include a supplied video with captions and a transcript.
- Links and asset paths work across all pages.
- The form is clearly described as a practice form; it does not claim to save registrations.

**Hints:** Plan the three pages first, build the content structure, and test the form with both valid and invalid sample entries.

**Suggested solution:** Provide separate example markup and explain table headers, label associations, and form limitations.
