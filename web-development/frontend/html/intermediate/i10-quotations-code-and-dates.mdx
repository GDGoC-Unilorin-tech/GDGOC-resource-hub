## What you will learn

- Mark quotations and work titles appropriately.
- Display code as text.
- Provide machine-readable dates.

## Before you begin

Complete the Beginner stage project and earlier lessons in this module. Work in a copy of your growing portfolio.

<Tip>Examples labelled as body snippets go inside your existing document's body, not inside the MDX source of a live website. Complete HTML documents can be saved directly as .html files. Read the explanation for any head-only or intentionally broken examples.</Tip>

## Quotations and attribution

`blockquote` marks an extended quotation; `q` marks an inline quotation. `cite` identifies a work's title, not a person's name. A blockquote cite attribute can identify a source URL, but it does not display attribution for the reader—write visible attribution too.

## Show code without running it

`code` identifies code and `pre` preserves whitespace. Escape angle brackets with character references when showing HTML source; otherwise the browser interprets the markup.

## Dates humans and machines can read

`time` can pair readable text with a valid `datetime` value. Use an unambiguous year-month-day value for a date. If you include a time-zone-specific instant, supply an appropriate offset rather than assuming every reader shares your location.

## Worked example

```html
<p>Completed on <time datetime="2026-10-12">12 October 2026</time>.</p>
<blockquote><p>Small practice sessions help me keep learning.</p></blockquote>
<p>From my fictional journal, <cite>Learning Notes</cite>.</p>
<pre><code>&lt;p&gt;Hello, HTML!&lt;/p&gt;</code></pre>
```

The quote is original fictional sample text. The browser displays the HTML snippet as text, preserving the code block whitespace.

<Note>Do not use blockquote merely to indent ordinary text.</Note>

## Completion checklist

- [ ] datetime matches the displayed date.
- [ ] Quotation attribution is visible.
- [ ] cite names a work rather than its author.
- [ ] HTML source displays as code instead of becoming a link.

<Accordion title="View a suggested solution">

```html
<article>
  <h2>My first linked pages</h2>
  <p><time datetime="2026-10-12">12 October 2026</time></p>
  <blockquote><p>I learn by trying and reviewing.</p></blockquote>
  <p>From my journal, <cite>Practice Notes</cite>.</p>
  <p>My reminder is <q>test every link</q>.</p>
  <pre><code>&lt;a href="about.html"&gt;About&lt;/a&gt;</code></pre>
</article>
```

This implementation follows the requirements above. Compare it with your own attempt against each checklist item. Your wording and other valid choices may differ. Explain one decision you made and revise any unmet criterion.
