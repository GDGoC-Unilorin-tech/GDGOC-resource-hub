## Learning scope

`fieldset`, `legend`, instructions, `autocomplete`, help text associations, button types, and why placeholders do not replace labels.

## Practice challenge

Improve the registration form with grouped choices, clear instructions, and associated help text.

## Completion criteria

Groups have useful legends; labels stay visible; help text is connected where needed; required fields are explained.

## Content to develop

- Step-by-step explanation and code examples.
- Optional hints.
- Separately revealed suggested solution with explanation.
