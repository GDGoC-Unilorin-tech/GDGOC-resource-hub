## Learning scope

`header`, `nav`, `main`, `footer`, and when a neutral `div` is appropriate; semantic regions versus visual layout.

## Practice challenge

Restructure a supplied page into header, navigation, main content, and footer.

## Completion criteria

Main content has one visible `main`; navigation is meaningful; elements are chosen by purpose.

## Content to develop

- Step-by-step explanation and code examples.
- Optional hints.
- Separately revealed suggested solution with explanation.
