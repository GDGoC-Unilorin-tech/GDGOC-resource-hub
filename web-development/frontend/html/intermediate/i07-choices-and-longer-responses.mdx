## Learning scope

Radio buttons, checkboxes, `select`, `option`, and `textarea`; shared radio names; explicit option values.

## Practice challenge

Add a session choice, optional interests, and an accessibility-needs message to a registration form.

## Completion criteria

Only one radio option can be selected in its group; checkboxes allow multiple choices; every control has a label.

## Content to develop

- Step-by-step explanation and code examples.
- Optional hints.
- Separately revealed suggested solution with explanation.
