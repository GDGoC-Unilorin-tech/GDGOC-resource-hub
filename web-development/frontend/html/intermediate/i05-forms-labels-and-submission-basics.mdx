## Learning scope

`form`, `label`, `input`, `button`; `id` versus `name`; `action`; basic GET versus POST; what happens on submission.

## Practice challenge

Create a labelled search form using a provided local results-page destination and inspect its query string.

## Completion criteria

Label connects to input; named field appears in the URL; submit button has explicit type; learner explains that a results page needs processing logic to perform a search.

- Optional hints.
