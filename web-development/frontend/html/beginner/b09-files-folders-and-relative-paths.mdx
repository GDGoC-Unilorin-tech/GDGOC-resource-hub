## What you will learn

- Organise files consistently.
- Resolve sibling, child, and parent paths.
- Diagnose path mistakes.

## Before you begin

Complete the previous lesson in this module. Keep your editor and browser ready.

<Tip>Examples labelled as body snippets go inside your existing document's body, not inside the MDX source of a live website. Complete HTML documents can be saved directly as .html files. Read the explanation for any head-only or intentionally broken examples.</Tip>

## Paths start from a location

For the relative paths used here, imagine standing in the folder containing the current HTML document. A sibling filename stays in that folder. `images/profile.png` enters a child folder; `../index.html` goes up one folder.

Use forward slashes in web paths even on Windows. Keep filenames lowercase with hyphens and avoid spaces. Some deployed systems distinguish uppercase from lowercase even when your local computer does not.

A root-relative path starts with `/` and refers to the site's root. It is useful for the hub's own routes, but does not behave like a project-folder-relative path when opening local files. Use relative paths in the downloadable practice projects.

## Worked example

```html
<!-- From index.html at the project root -->
<a href="pages/about.html">About me</a>

<!-- From pages/about.html -->
<a href="../index.html">Home</a>
```

Create a pages folder beside index.html, then place about.html in it. The return link climbs from pages to the project root.

<Note>Do not paste a private absolute disk path into a website link.</Note>

## Practice challenge

Create index.html, pages/about.html, and pages/goals.html. Connect home to both nested pages; connect the nested pages to each other and home. Sketch the folder tree.

Attempt the task first. Save your source and inspect the result in your browser. Record what you expected and what you observed.

## Completion checklist

- [ ] The three files match the planned folder tree.
- [ ] Sibling links use sibling filenames.
- [ ] Nested pages return home using ../.
- [ ] All links work from their source page.

<Accordion title="View a suggested solution">

```html
<!-- index.html -->
<a href="pages/about.html">About</a>
<a href="pages/goals.html">Goals</a>
<!-- pages/about.html -->
<a href="goals.html">Goals</a>
<a href="../index.html">Home</a>
<!-- pages/goals.html -->
<a href="about.html">About</a>
<a href="../index.html">Home</a>
```

This implementation follows the requirements above. Compare it with your own attempt against each checklist item. Your wording and other valid choices may differ. Explain one decision you made and revise any unmet criterion.
