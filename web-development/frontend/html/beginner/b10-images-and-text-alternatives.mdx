## What you will learn

- Add an image using a local path.
- Write context-appropriate alternative text.
- Associate a caption and use accurate dimensions.

## Before you begin

Complete the previous lesson in this module. Keep your editor and browser ready.

<Tip>Examples labelled as body snippets go inside your existing document's body, not inside the MDX source of a live website. Complete HTML documents can be saved directly as .html files. Read the explanation for any head-only or intentionally broken examples.</Tip>

## An image needs a source and a purpose

`img` is a void element. Its `src` locates the file; `alt` provides a text alternative. Describe the information the image contributes in this context rather than automatically starting with “image of”. For a purely decorative image, use `alt=""` so assistive technology can skip it.

Do not omit alt simply because a caption exists. A caption is visible supporting text; alternative text serves a different purpose when the image cannot be perceived.

## Dimensions and captions

Use `width` and `height` for the image's actual dimensions or an accurate proportional display size. Their relationship helps the browser reserve space. A `figure` groups self-contained content; `figcaption` supplies its caption. It is not mandatory for every image.

Download the local practice image below, save it in an images folder, and use its exact filename. It is 960 × 540 pixels.

## Worked example

```html
<figure>
  <img src="images/study-wide.png"
       alt="Three learning stages: learn, practise, and build"
       width="960" height="540">
  <figcaption>My approach to learning web development.</figcaption>
</figure>
```

[Download the practice image](/assets/html/study-wide.png). It is an original course diagram. The alternative text communicates its three stages and the caption explains why it is here.

<Note>Only reuse images you created or have permission to use. Supplied course diagrams may be used for these exercises.</Note>
