## Learning scope

`img`, `src`, context-appropriate `alt`, decorative images, intrinsic width and height, `figure`, and `figcaption`.

## Practice challenge

Add a meaningful image with a text alternative and a caption to the profile page.

## Completion criteria

Image loads; alternative text serves its purpose; dimensions are appropriate; caption is associated with the image.

## Content to develop

- Step-by-step explanation and code examples.
- Optional hints.
- Separately revealed suggested solution with explanation.
