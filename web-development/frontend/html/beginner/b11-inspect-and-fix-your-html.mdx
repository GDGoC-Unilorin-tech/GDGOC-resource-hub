## Learning scope

View source versus the browser's Elements panel; common nesting mistakes; broken links and images; checking rendered output; comments.

## Practice challenge

Repair a supplied page with a broken image path, incorrect nesting, and a missing fragment target.

## Completion criteria

All listed defects are repaired; learner checks both markup and browser output.

- Optional hints.
