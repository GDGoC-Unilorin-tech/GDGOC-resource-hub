## Learning scope

Unordered, ordered, and description lists; list items; simple nested lists.

## Practice challenge

Create a packing list, ordered setup instructions, and a short glossary.

## Completion criteria

Correct list types; valid list children; nested list is inside its parent item.

## Content to develop

- Step-by-step explanation and code examples.
- Optional hints.
- Separately revealed suggested solution with explanation.
