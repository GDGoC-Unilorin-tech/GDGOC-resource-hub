## What you will learn

- Choose ordered, unordered, and description lists.
- Write valid list items.
- Nest a list within a list item.

## Before you begin

Complete the previous lesson in this module. Keep your editor and browser ready.

<Tip>Examples labelled as body snippets go inside your existing document's body, not inside the MDX source of a live website. Complete HTML documents can be saved directly as .html files. Read the explanation for any head-only or intentionally broken examples.</Tip>

## Choose the list for the content

Use `ul` when the order of items does not matter, such as interests. Use `ol` when sequence or ranking matters, such as setup instructions. Their items use `li`.

Use `dl` for term–description relationships: `dt` gives a term and `dd` its description. This works for a glossary without pretending the entries are steps.

## Nested lists

A nested list belongs inside the `li` it expands. Do not place a nested `ul` directly between sibling list items. The indentation in your editor makes the relationship easier to inspect.

## Worked example

```html
<h2>Study supplies</h2>
<ul>
  <li>A notebook</li>
  <li>Practice files
    <ul>
      <li>index.html</li>
      <li>about.html</li>
    </ul>
  </li>
</ul>
<h2>Start practising</h2>
<ol>
  <li>Open the editor.</li>
  <li>Save the file.</li>
  <li>Refresh the browser.</li>
</ol>
<dl>
  <dt>Browser</dt>
  <dd>Software that displays web pages.</dd>
</dl>
```

The supplies have no required order; the workflow does. The glossary describes a term. The nested list stays inside “Practice files”.

<Note>Do not type bullet characters to imitate a list; use list markup.</Note>
