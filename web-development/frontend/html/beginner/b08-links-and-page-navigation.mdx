## Learning scope

`a`, meaningful link text, absolute and relative URLs, fragment links, unique IDs, and deliberate new-tab behaviour.

## Practice challenge

Add a link to a second local page and a link that jumps to a section on the current page.

## Completion criteria

Both links work; fragment target exists; link labels describe their destination.

## Content to develop

- Step-by-step explanation and code examples.
- Optional hints.
- Separately revealed suggested solution with explanation.
