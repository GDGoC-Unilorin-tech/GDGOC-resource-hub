## What you will learn

- Create descriptive links.
- Distinguish absolute, relative, and fragment destinations.
- Use deliberate new-tab behaviour.

## Before you begin

Complete the previous lesson in this module. Keep your editor and browser ready.

<Tip>Examples labelled as body snippets go inside your existing document's body, not inside the MDX source of a live website. Complete HTML documents can be saved directly as .html files. Read the explanation for any head-only or intentionally broken examples.</Tip>

## A link has text and a destination

`a` with `href` creates a hyperlink. Its visible text should describe the destination, such as “Read my learning plan”, rather than an isolated “click here”.

A relative destination such as `about.html` is resolved from the current document's URL. An absolute URL includes its scheme and host, such as `https://example.com/`. We keep course learning inside the hub, but this distinction matters when you author websites.

## Jump within a page

Use a unique `id` on the destination and `#` plus that ID in the link. The ID value itself has no hash. A fragment can also follow a filename: `about.html#goals`.

Links normally open in the same tab. If a genuine need calls for `target="_blank"`, tell visitors it opens a new tab and explicitly add `rel="noopener"`. Use normal same-tab links for your local course projects.

## Worked example

```html
<p><a href="about.html">Read about my interests</a></p>
<p><a href="#goals">Jump to my goals</a></p>
<h2 id="goals">My goals</h2>
<p>Build a useful portfolio.</p>
```

Create about.html beside this page before testing the first link. The fragment changes the URL and may move the viewport if the destination is outside the visible area.

<Note>An href is not a promise that a file exists. Create and test the destination.</Note>
