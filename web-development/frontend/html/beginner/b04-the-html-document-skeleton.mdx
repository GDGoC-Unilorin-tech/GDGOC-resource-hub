## Learning scope

`<!doctype html>`, `html`, `lang`, `head`, `body`, character encoding, page title, and viewport metadata; head information versus visible content.

## Practice challenge

Turn the first page into a complete document with an appropriate language and browser-tab title.

## Completion criteria

Required document structure is present; metadata sits in the head; visible content sits in the body.

## Content to develop

- Step-by-step explanation and code examples.
- Optional hints.
- Separately revealed suggested solution with explanation.
