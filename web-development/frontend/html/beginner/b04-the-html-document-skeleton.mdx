## The document is a tree

An HTML document has one `html` root element. Inside it, `head` contains information about the document and `body` contains the page content. The doctype is a declaration before the root; it tells the browser to use standards mode.

## What belongs in the head?

- `lang="en"` on `html` identifies English as the main content language. Choose the language that matches your content.
- `meta charset="UTF-8"` declares the character encoding, allowing text such as accented names to display correctly. Put it near the beginning of the head.
- `title` identifies this document in the browser tab and helps visitors distinguish pages.
- The viewport metadata tells mobile browsers to use the device width rather than a wide virtual page. It does not itself make every layout responsive.

The `head` is different from a page heading. A visible heading such as `h1` belongs in `body`.

## Worked example

```html
<!doctype html>
<html lang="en">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Amina's learning page</title>
  </head>
  <body>
    <h1>My learning page</h1>
    <p>I am building my HTML foundation.</p>
  </body>
</html>
```

Save this as `index.html`. The browser tab shows the title; the page shows the heading and paragraph. Change them separately to observe the difference.

<Note>Do not disable browser zoom in viewport settings. Visitors may need to magnify text.</Note>
