## Learning scope

`strong`, `em`, `small`, `br`, `hr`, and character references; meaningful emphasis; line breaks versus paragraphs; why repeated spaces do not create layouts.

## Practice challenge

Mark up an announcement with an important deadline, an emphasised instruction, and a literal `<` character.

## Completion criteria

Emphasis reflects meaning; characters display correctly; spacing is not built from repeated breaks or spaces.

## Content to develop

- Step-by-step explanation and code examples.
- Optional hints.
- Separately revealed suggested solution with explanation.
