The core course is self-contained. These optional references help you check details and continue learning after completing the HTML building challenge.

## Foundations and document structure

- [MDN: Structuring content with HTML](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/Structuring_content) — Revisit text, links, lists, document structure, and practical challenges.
- [HTML Living Standard](https://html.spec.whatwg.org/multipage/) — The detailed specification. Use it to investigate an element's content rules after learning the basics.

## Images and media

- [MDN: Responsive images](https://developer.mozilla.org/en-US/docs/Web/HTML/Guides/Responsive_images) — Resource selection, width descriptors, and art direction.
- [MDN: Text tracks](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/track) — Track kinds, language information, and WebVTT behaviour.

## Forms and accessible content

- [W3C WAI: Forms tutorial](https://www.w3.org/WAI/tutorials/forms/) — Labels, instructions, grouping, and accessible form feedback.
- [MDN: Input reference](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/input) — Input types, attributes, and constraints.
- [W3C WAI: Images tutorial](https://www.w3.org/WAI/tutorials/images/) — Choosing text alternatives according to an image's purpose.
- [W3C WAI: Tables tutorial](https://www.w3.org/WAI/tutorials/tables/) — Header associations and accessible data relationships.

## Review and embedding

- [Nu HTML Checker](https://validator.w3.org/nu/) — Check markup by text or file. Avoid uploading private content; use manual/source review or a locally operated checker for confidential files. Validity does not prove complete accessibility.
- [MDN: iframe reference](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/iframe) — Embedding, sandbox permissions, and limitations.

## Demonstrate what you learned

Keep your portfolio files, checkpoint evidence, and final audit. Be ready to explain your HTML choices and show a visitor journey. A technical-team reviewer can assess contribution readiness; completion alone does not grant production access.

## What comes next?

Your HTML portfolio is the foundation for CSS styling and later JavaScript behaviour. Those courses will follow the same modules, practice, checkpoints, and project pattern. Their content is separate from this HTML course.
