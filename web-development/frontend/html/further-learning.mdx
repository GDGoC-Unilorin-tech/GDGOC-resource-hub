The core course is self-contained. These optional Google resources help you review topics and continue learning after completing the HTML building challenge. The linked articles are free to read on web.dev and Chrome for Developers.

## Foundations and document structure

- [web.dev: Learn HTML](https://web.dev/learn/html) — Review HTML through a structured course covering text, links, lists, semantic elements, and more.
- [web.dev: Document structure](https://web.dev/learn/html/document-structure) — Revisit the doctype, document language, head, metadata, and body.

## Images and media

- [web.dev: Learn Images](https://web.dev/learn/images) — Explore image formats, responsive image markup, resource selection, and performance.
- [web.dev: Video and audio accessibility](https://web.dev/learn/accessibility/video-audio) — Learn how captions, transcripts, and audio descriptions support access to media.

## Forms and accessible content

- [web.dev: Learn Forms](https://web.dev/learn/forms) — Study form controls, labels, validation, and accessible form design.
- [web.dev: Help users enter data in forms](https://web.dev/learn/forms/form-fields) — Choose suitable form fields and input types for the information you need.
- [web.dev: Accessible images](https://web.dev/learn/accessibility/images) — Choose text alternatives according to an image's purpose.
- [web.dev: Tables](https://web.dev/learn/html/tables) — Review captions, table structure, and relationships between headers and data cells.

## Review and embedding

- [Chrome DevTools: View and change the DOM](https://developer.chrome.com/docs/devtools/dom) — Inspect the browser's document tree and investigate how it differs from your source HTML.
- [Chrome for Developers: Introduction to Lighthouse](https://developer.chrome.com/docs/lighthouse/overview) — Run automated audits and investigate reported issues.
- [Chrome for Developers: Securely embed content](https://developer.chrome.com/blog/embed-content) — Explore iframe embedding, sandbox restrictions, and permissions. Some examples go beyond this HTML course.

<Note>
DevTools inspection and Lighthouse audits do not replace HTML conformance validation. An automated audit also cannot prove complete accessibility. Continue the source review, keyboard checks, and other manual checks taught in the course.
</Note>

## Demonstrate what you learned

Keep your portfolio files, checkpoint evidence, and final audit. Be ready to explain your HTML choices and show a visitor journey. A technical-team reviewer can assess contribution readiness; completion alone does not grant production access.

## What comes next?

Your HTML portfolio is the foundation for CSS styling and later JavaScript behaviour. Those courses will follow the same modules, practice, checkpoints, and project pattern. Their content is separate from this HTML course.
