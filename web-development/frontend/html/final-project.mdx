### Project brief

Create an HTML-only website for a fictional campus club. A new student should be able to understand the club, explore events and resources, and complete a practice membership form.

Use fictional contact details and sample data. Provide all required image variants, a short media file, a caption file, and transcript text with the challenge so learners do not need external asset searches or additional production tools.

### Required pages

1. **Home:** Club introduction, a meaningful image, and navigation to the other pages.
2. **About:** Club purpose, activities, and logically organised supporting content.
3. **Events:** Event information, machine-readable dates, and a captioned schedule table.
4. **Resources:** Internally linked resource descriptions, a responsive image example, and an FAQ using `details` and `summary`.
5. **Join:** A clearly labelled practice membership form with grouped choices, help text, and suitable browser validation.

Include the supplied captioned video and transcript on a page where it fits. The resources page contains supplied sample content; it does not require external learning links. An iframe is optional in the final project because it may not serve this site's content needs.

### Completion checklist

- All five pages open locally and navigation works from every page.
- Every page has a complete skeleton, appropriate language, unique title, and relevant description.
- Headings and semantic elements reflect the content's structure.
- Links describe their destinations; IDs are unique; fragment links work where used.
- Meaningful images have suitable text alternatives; decorative images, if any, use empty alternatives.
- Image paths and dimensions are correct; responsive image markup uses accurate asset information.
- Data table has a caption and associated headers.
- Every form control has a label; related controls are grouped; buttons have suitable types.
- Required fields and input constraints behave as expected with sample data.
- Practice form clearly states that it does not create or store membership registrations.
- Video has controls, working captions, and a transcript.
- FAQ works using native browser disclosure behaviour.
- Keyboard navigation and skip links have been checked.
- Markup has been reviewed for errors; all discovered issues are fixed or documented.
- No CSS or JavaScript is required to meet the brief.
- Learner provides a short explanation of their folder structure and three HTML decisions.

### Hints

Release hints separately from the brief: plan the pages and assets; build a reusable document skeleton; write content before adding complex elements; test paths from each page; test the form with invalid values; finish with an audit.

### Suggested solution

Provide a separate example implementation after the challenge, including the folder structure, all five HTML files, and an annotated review checklist. Explain alternative valid choices. Learners should compare the solution after attempting the project.
