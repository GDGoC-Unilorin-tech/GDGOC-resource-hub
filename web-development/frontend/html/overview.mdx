HTML stands for **HyperText Markup Language**. It describes
the structure and meaning of content on a web page, including
headings, paragraphs, links, images, and forms.

In this course, you will start with your first HTML file and
work towards building a complete website with several connected
pages.

## Who is this course for?

This course is for beginners. You do not need any previous
coding experience.

We will explain how to create your files, write your code,
and open your pages in a browser.

## What you will learn

By the end of this course, you will be able to:

- Create HTML files and open them in a browser.
- Organise content with headings, paragraphs, and lists.
- Connect pages using links.
- Add images with useful text alternatives.
- Structure pages using meaningful HTML elements.
- Build tables and accessible forms.
- Add audio and video.
- Review your HTML and fix common mistakes.
- Build a website with several connected pages.

HTML focuses on content and structure. Your pages will look
simple at first. You will learn styling and layouts in the
CSS course, followed by interactive behaviour in JavaScript.

## What you need

- A computer.
- A web browser.
- A text editor, such as Visual Studio Code.
- A folder for your practice files.

The setup lesson will walk you through creating and opening
your first page.

## Your learning journey

### Beginner: Your first web pages

Start with the basics: files, elements, document structure,
text, lists, links, and images.

**Stage project:** Build a personal introduction website.

### Intermediate: Structured and accessible content

Learn semantic page structure, accessibility fundamentals,
tables, forms, and media.

**Stage project:** Build a community event website.

### Advanced: Robust HTML and native browser features

Explore responsive images, native disclosure widgets,
embedded content, metadata, and HTML auditing.

**Stage project:** Build a resource directory.

### Final building challenge

Bring your skills together by building a campus club website
with a home page, about page, events, resources, and a practice
membership form.

## How to work through the course

1. Read the explanation and try the examples.
2. Attempt the practice challenge yourself.
3. Use the hints if you get stuck.
4. Check your work against the completion checklist.
5. Compare your approach with the suggested solution.
6. Move to the next lesson.

Complete each stage project before starting the next level.
This will help you check that you understand the earlier topics.

Different solutions can be correct. Focus on meeting the
requirements and understanding your HTML.
