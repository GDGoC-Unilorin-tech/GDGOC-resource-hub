## Learning scope

Review title, language, encoding, and viewport; description metadata; nested language changes; correct use of link metadata where applicable.

## Practice challenge

Improve metadata for three pages and mark up a supplied phrase in a different language.

## Completion criteria

Titles and descriptions fit each page; language attributes are accurate; learner avoids claims that metadata guarantees search rankings.

## Content to develop

- Step-by-step explanation and code examples.
- Optional hints.
- Separately revealed suggested solution with explanation.
