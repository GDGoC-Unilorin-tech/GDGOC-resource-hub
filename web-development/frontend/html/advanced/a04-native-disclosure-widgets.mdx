## Learning scope

`details` and `summary`; useful disclosure labels; keyboard behaviour; deciding what content should stay immediately visible.

## Practice challenge

Create an FAQ with native disclosure widgets.

## Completion criteria

Every widget has a meaningful summary; keyboard activation works; essential task instructions remain visible outside disclosures.
