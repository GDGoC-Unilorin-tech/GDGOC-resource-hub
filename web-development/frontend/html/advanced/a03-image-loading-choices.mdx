## Learning scope

Intrinsic dimensions; lazy loading below-the-fold images; why prominent images should not automatically be lazy loaded; descriptive file organisation.

## Practice challenge

Review a gallery and assign dimensions and loading behaviour based on the images' placement.

## Completion criteria

Dimensions match assets; loading choices have reasons; the main introductory image is not indiscriminately lazy loaded.

## Content to develop

- Step-by-step explanation and code examples.
- Optional hints.
- Separately revealed suggested solution with explanation.
