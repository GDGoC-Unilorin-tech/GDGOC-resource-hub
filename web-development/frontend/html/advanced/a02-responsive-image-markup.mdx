## Learning scope

`srcset`, `sizes`, `picture`, `source`, fallback images, and the difference between resolution selection and art direction.

## Practice challenge

Use supplied image variants to offer suitable resolutions, then create a separate cropped-image example with `picture`.

## Completion criteria

Descriptors match the supplied files; fallback image and alternative text are present; learner explains both use cases without needing CSS.
