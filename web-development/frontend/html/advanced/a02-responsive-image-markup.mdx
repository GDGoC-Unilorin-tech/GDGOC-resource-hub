## What you will learn

- Distinguish resolution selection from art direction.
- Describe image candidates accurately.
- Provide an img fallback and text alternative.

## Before you begin

Complete the Intermediate portfolio milestone and earlier lessons in this module.

<Tip>Examples labelled as body snippets go inside your existing document's body, not inside the MDX source of a live website. Complete HTML documents can be saved directly as .html files. Read the explanation for any head-only or intentionally broken examples.</Tip>

## Two different problems

Resolution selection offers versions of the same composition so the browser can choose a suitable resource. Art direction changes the composition, such as a wide diagram versus a tall arrangement for a narrow screen.

For a fixed 480-pixel-wide slot, `1x` and `2x` density descriptors can offer 480- and 960-pixel resources. With width descriptors such as `480w`, each value must match the file's actual intrinsic width. `sizes` describes the intended display slot for width-descriptor candidates; it does not style that slot.

## Picture selects a source

`picture` can provide source candidates under media conditions, then an `img` fallback. The img supplies alternative text. The browser's selection can depend on density, cache, and other factors, so do not assume it always chooses a particular resolution.

Download the practice pack from the media lesson. It includes study-small.png (480 × 270), study-wide.png (960 × 540), and study-tall.png (480 × 640).

## Worked example

```html
<!-- Resolution selection for a fixed-width image -->
<img src="images/study-small.png"
     srcset="images/study-small.png 1x, images/study-wide.png 2x"
     width="480" height="270" alt="Learn, practise, build">

<!-- Art direction: a different composition on a narrow viewport -->
<picture>
  <source media="(max-width: 600px)" srcset="images/study-tall.png"
          width="480" height="640">
  <img src="images/study-wide.png" width="960" height="540"
       alt="Three stages: learn, practise, and build">
</picture>
```

These are resource-selection examples, not a complete responsive CSS layout. The fixed 480px image can overflow a very narrow viewport; later CSS will control display sizing. Inspect currentSrc in DevTools or the Network panel while resizing and reloading.

<Note>Responsive resource selection and responsive visual sizing are related but distinct.</Note>
