## Before you begin

## A page within a page

`iframe` embeds another document. Give it a concise title so users can identify the frame. Width and height describe its display box; `loading="lazy"` can defer a frame that is not needed immediately.

Create a small project-notes.html file beside your projects page. A direct link lets visitors choose to open the same content without using the frame.

## Embedding has boundaries

Remote sites may block framing using security policies. You cannot fix this by changing your markup. Third-party embeds can also introduce tracking, loading cost, and dependence on another service.

An empty `sandbox` applies a restrictive set of permissions. Tokens selectively restore capabilities. Do not add permissions blindly; particularly avoid treating allow-scripts plus allow-same-origin on a same-origin frame as effective isolation. Our static local note needs neither.

## Worked example

```html
<iframe src="project-notes.html" title="Notes about my HTML project"
        width="480" height="240" loading="lazy" sandbox></iframe>
<p><a href="project-notes.html">Open the project notes as a page</a></p>
```

Create a complete project-notes.html document containing a heading and paragraph. The static text renders in the restricted frame; test the direct link as well.

<Note>Only use a frame where the content benefits from it. The final portfolio does not require an unnecessary embed.</Note>
