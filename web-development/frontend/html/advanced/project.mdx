> Authoring draft: this page defines curriculum scope. Full teaching content and solutions are pending.

Build a three-page directory using supplied fictional resource records: a directory home page, a resource detail page, and a contribution form.

**Requirements and completion checklist**

- Resource entries use meaningful structure and descriptive internal links.
- A responsive image uses supplied variants and appropriate fallback markup.
- Images include accurate dimensions and justified loading choices.
- An FAQ uses native disclosure widgets.
- A titled iframe displays supplied local content and includes a direct-link alternative.
- Each page has appropriate metadata and language information.
- The contribution form uses accessible controls and clearly states that submissions are not stored.
- An audit checklist records markup, navigation, keyboard, and asset checks.

**Hints:** Reuse the document structure you already understand, add one advanced feature at a time, and recheck the site after each addition.

**Suggested solution:** Provide separate markup, an asset map, and an example audit report. Explain decisions rather than presenting one structure as the only acceptable answer.
