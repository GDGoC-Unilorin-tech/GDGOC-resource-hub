## What you will build

Take a small practice website from a working folder through commits, bug investigation, tests, and a reviewed release. Apply those habits to your existing portfolio and the [Frontend Capstone](/web-development/frontend/capstone).

## Entry requirements

Start Beginner after your first HTML pages. Intermediate assumes basic CSS and JavaScript functions/events. Advanced assumes you can repair the practice site's bugs and explain its modules. Use your existing editor, a terminal, Git, Node.js, and Chrome. Git and GitHub are not Google products; they are collaboration tools used in this course. Optional external learning references at the end are Google-affiliated.

## Your course

| Stage | Skills | Evidence |
| --- | --- | --- |
| Beginner | Workspace, snapshots, branches, review | Reproducible practice repository |
| Intermediate | Elements, Sources, Network | Three documented repairs |
| Advanced | Regression tests, usability review, release | Tested release package |

Each stage has three lessons, a checkpoint, and a project. Attempt the challenges before opening hints and suggested solutions. The final challenge applies the workflow to your own portfolio.

[Download the practice pack](/assets/workflow/workflow-practice-pack.zip). Read README.md in the extraction root before starting. The starter contains intentional bugs; the solution is for comparison after attempting the repairs.

<Note>Completion uses evidence and checklists. The hub does not track progress, automatically grade work, or enforce stage locks. Remote collaboration and deployment require your own accounts; record them as incomplete if you cannot practise them yet.</Note>
