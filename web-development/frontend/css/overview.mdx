CSS means **Cascading Style Sheets**. It controls how your HTML content is presented: typography, colour, spacing, layout, and visual states. In this course you will style the portfolio you built in HTML and keep it ready for later JavaScript behaviour.

## Who this course is for

You do not need previous CSS experience. You should be comfortable creating HTML files, linking pages, using semantic elements, and building labelled forms. [Complete the HTML course](/web-development/frontend/html/overview) first if you need those foundations.

## What you will build

| Level | Skills | Portfolio milestone |
| --- | --- | --- |
| Beginner | Selectors, cascade, box model, units, typography, colour, decoration, and flow | Readable, consistently styled pages |
| Intermediate | Flexbox, Grid, media queries, fluid sizing, media, positioning, states, tokens, and debugging | A responsive portfolio usable at different widths |
| Advanced | Layers, container queries, subgrid, logical properties, themes, motion, print, and auditing | Reusable, adaptable components with tested fallbacks |
| Final challenge | Integrate and demonstrate the complete stylesheet | An audited portfolio ready for JavaScript enhancement |

## Tools and practice materials

- Your existing text editor and a current browser with developer tools.
- A copy of your HTML portfolio, or the portfolio in the supplied [CSS practice pack](/assets/css/css-practice-pack.zip).
- A folder for each milestone and a short record of your tests.

The pack contains **27 runnable topic examples**, separate suggested CSS solutions, local images, and the starting portfolio. Most CSS exercises work by opening index.html directly. For the portfolio's media text-track checks, use your editor's local server or the Python server instructions in the pack README. No build system or package installation is required.

## How to learn here

Read the explanation, predict the result, run the example, and attempt the challenge. Open hints when needed and compare the suggested solution after trying. Complete the module checkpoint with evidence, then combine the skills in a stage project. Each topic has its own page with Previous and Next navigation.

Code blocks are examples, not an embedded code editor. Save code in your practice files to run it. Your pages may differ from the suggested design while meeting the same requirements.

<Tip>Use a single shared stylesheet for your portfolio pages. Keep lesson experiments in their own folders so unrelated selectors do not interfere with each other.</Tip>
