## What you will learn

- Respond to prefers-color-scheme.
- Check controls, links, and focus in both themes.

To build the example manually, use your standard HTML document skeleton, add `<link rel="stylesheet" href="styles.css">` inside its head, and put the HTML below inside its body.

## Understand the idea

A theme needs coherent foreground, background, border, link, and focus colours. Inverting a screenshot or changing only the page background leaves controls and low-contrast text behind. Use custom properties named by role so components inherit a consistent palette.

Prefers-color-scheme reflects the user’s system or browser preference. A media query can override tokens for a dark theme without JavaScript. The color-scheme property also lets native controls and browser UI adapt; it does not invent your component colours for you.

This course follows the system preference. A manual toggle with saved state would need additional behaviour, normally taught with JavaScript. Inspect contrast in both themes and do not disable forced-colour adjustments just to preserve branding.

## Worked example

### HTML body

```html
<h1>Theme preview</h1>
<section class="panel"><h2>My portfolio</h2><p><a href="#notes">Read notes</a></p><label for="query">Practice search</label><input id="query" type="search"></section><p id="notes">Check both themes.</p>
```

### styles.css

```css
:root { color-scheme: light; --surface: #ffffff; --text: #202124; --link: #174ea6; --border: #747775; }
body { background: var(--surface); color: var(--text); }
a { color: var(--link); }
.panel { padding: 1rem; border: 1px solid var(--border); }
:focus-visible { outline: 3px solid var(--link); outline-offset: 3px; }
@media (prefers-color-scheme: dark) {
  :root { color-scheme: dark; --surface: #202124; --text: #f1f3f4; --link: #aecbfa; --border: #9aa0a6; }
}
```

## Try it and observe

Emulate light and dark colour schemes in DevTools Rendering. Check text, links, input appearance, and the keyboard focus outline. Record the actual contrast pairs rather than assuming the dark palette is readable.

## Practice challenge

Add --panel as #f8fafd in light mode and #303134 in dark mode, then use it on .panel. Keep all existing states usable.

Save your changes, reload, and compare the observed result with your prediction. Keep a short note of what changed and why.

## Check your understanding

Does color-scheme:dark automatically create a complete dark component theme?

<Accordion title="Check your answer">

No. It informs browser-provided UI. Your own backgrounds, text, borders, and states still need appropriate styles and testing.
