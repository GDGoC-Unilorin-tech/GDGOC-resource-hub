## Skills to demonstrate

Use logical spacing for a notice, add light/dark theme tokens, and provide a small optional link transition. Test direction, colour preference, keyboard focus, and reduced motion.

Use your own portfolio copy or the `portfolio` folder in the [practice pack](/assets/css/css-practice-pack.zip). Keep a separate checkpoint copy. Work from the requirements before consulting a suggested implementation.

## Completion criteria

- [ ] Logical accents follow text direction.
- [ ] Both themes have measured contrast and visible focus.
- [ ] Reduced motion removes movement without removing functionality.
- [ ] I can explain the selectors and declarations I chose.
- [ ] My saved stylesheet produces the result after reloading.

## Test and record evidence

Use a note or table with **page, viewport or preference, action, expected result, observed result, repair, and retest**. Check the behaviours named in the criteria, not just whether the screenshot looks attractive. Use 320px and 1280px as two starting widths; add any breakpoint boundaries relevant to your implementation. Test focus with the keyboard and try longer text.

Mark each criterion **Met**, **Needs revision**, or **Not tested**. A sample implementation is not evidence that your work passed. Retest after changing the source.
