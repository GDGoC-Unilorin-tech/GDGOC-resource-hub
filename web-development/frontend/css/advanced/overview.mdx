## Before you begin

Complete the Intermediate CSS project. You should already have responsive navigation, a project grid, usable controls, and a documented layout repair.

Copy your previous portfolio folder before starting. The [practice pack](/assets/css/css-practice-pack.zip) includes a semantic HTML portfolio if you need a common starting point, plus isolated runnable lesson examples. Use local files; no account, API key, external font, or paid tool is required.

## Your learning outcomes and module order

### Architecture and progressive layout

Organise the stylesheet into explicit layers, create a container-aware profile, and enhance project alignment with subgrid. Keep a readable fallback for both newer layout features.

- [Organise the cascade with layers](/web-development/frontend/css/advanced/a01-cascade-layers)
- [Adapt components with container queries](/web-development/frontend/css/advanced/a02-container-queries)
- [Align card content with subgrid](/web-development/frontend/css/advanced/a03-subgrid-and-fallbacks)
- [Module checkpoint](/web-development/frontend/css/advanced/checkpoint-progressive-layout)
### Direction, themes, and motion

Use logical spacing for a notice, add light/dark theme tokens, and provide a small optional link transition. Test direction, colour preference, keyboard focus, and reduced motion.

- [Use logical properties for adaptable layouts](/web-development/frontend/css/advanced/a04-logical-properties)
- [Build light and dark themes with tokens](/web-development/frontend/css/advanced/a05-themes-and-user-preferences)
- [Use transitions with reduced-motion support](/web-development/frontend/css/advanced/a06-transitions-and-reduced-motion)
- [Module checkpoint](/web-development/frontend/css/advanced/checkpoint-user-preferences)
### Animation, print, and evidence

Add one finite optional milestone animation, provide readable print output, and audit every portfolio page. Keep a reproducible defect and repair record with honest limitations.

- [Create a restrained keyframe animation](/web-development/frontend/css/advanced/a07-keyframes-and-finite-animation)
- [Maintain styles and support printing](/web-development/frontend/css/advanced/a08-maintainable-css-and-print)
- [Audit and demonstrate a styled website](/web-development/frontend/css/advanced/a09-audit-and-demonstrate)
- [Module checkpoint](/web-development/frontend/css/advanced/checkpoint-final-audit)
