The core lessons and projects live inside this hub. These optional Google resources help you review and explore further after completing the final challenge. Articles are free to read; the course does not require purchasing a product or using a paid service.

## Foundations

- [web.dev: Learn CSS](https://web.dev/learn/css) — Review the broader CSS course and choose topics to revisit.
- [web.dev: Box model](https://web.dev/learn/css/box-model) — Review how dimensions, padding, borders, and margins relate.
- [web.dev: Colour and contrast](https://web.dev/learn/accessibility/color-contrast) — Review contrast and the limits of communicating through colour alone.

## Responsive layouts

- [web.dev: Flexbox](https://web.dev/learn/css/flexbox) — Revisit one-dimensional alignment and flexible items.
- [web.dev: Grid](https://web.dev/learn/css/grid) — Explore tracks and two-dimensional layout.
- [web.dev: Learn Responsive Design](https://web.dev/learn/design) — Continue with adaptive layouts, content, and design decisions.

## Advanced components and user preferences

- [Chrome for Developers: Cascade layers](https://developer.chrome.com/blog/cascade-layers) — Understand layer ordering and how it interacts with the cascade.
- [web.dev: Container queries](https://web.dev/learn/css/container-queries) — Explore components that respond to their available space.
- [web.dev: CSS subgrid](https://web.dev/articles/css-subgrid) — Review sharing parent tracks with nested layouts.
- [web.dev: Reduced motion](https://web.dev/articles/prefers-reduced-motion) — Explore adapting motion to user preferences.
- [web.dev: Animations](https://web.dev/learn/css/animations) — Revisit keyframes and animation properties.

## Debugging and review

- [Chrome DevTools: CSS features reference](https://developer.chrome.com/docs/devtools/css/reference) — Inspect rules and computed styles while diagnosing problems.
- [Chrome DevTools: Accessibility features](https://developer.chrome.com/docs/devtools/accessibility/reference) — Inspect accessibility information alongside manual keyboard and content checks.

## What comes next?

[Continue to JavaScript](/web-development/frontend/javascript/overview) to add behaviour to the structured and styled portfolio. The [Frontend Capstone](/web-development/frontend/capstone) connects your skills into a complete project. Keep your CSS evidence and source files ready for a reviewer; completing a course alone does not grant production access.
