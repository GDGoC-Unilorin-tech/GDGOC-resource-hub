## Understand the idea

Flexbox lays out direct children along a main axis and a cross axis. The default main axis follows the row direction. Justify-content distributes free space along the main axis; align-items controls alignment across it. Gap creates spacing between items without needing special margins on the first or last item.

Flex items can shrink, but long content may still have an automatic minimum size. Use min-width:0 on an item that should be allowed to shrink, then handle the text inside it appropriately. Flex-wrap lets a navigation row break into more rows when space is insufficient.

Do not use order or row-reverse just to make a visually convenient reading order. Keyboard and assistive-technology order generally follows the DOM, so the HTML order should already make sense.

## Worked example

### HTML body

```html
<h1>Portfolio navigation</h1>
<nav class="nav" aria-label="Practice"><a href="#home">Home</a><a href="#projects">My projects</a><a href="#contact">Contact and collaboration</a></nav>
<section id="home"><h2>Home</h2></section><section id="projects"><h2>Projects</h2></section><section id="contact"><h2>Contact</h2></section>
```

### styles.css

```css
.nav { display: flex; flex-wrap: wrap; gap: 0.75rem; align-items: center; }
.nav a { padding: 0.75rem; }
```

## Try it and observe

Resize to 320px. Links should wrap rather than disappear. Tab through them and compare focus order with their visual order. Use the flex overlay in DevTools to identify the container and gaps.

## Practice challenge

Keep wrapping navigation, set gap to 1rem, and give each link a visible 1px border. Do not reorder the links or reduce their labels.

Save your changes, reload, and compare the observed result with your prediction. Keep a short note of what changed and why.

<Accordion title="Need a hint?">

Flexbox belongs on the parent; spacing and borders can then be applied to the links.

</Accordion>

## Check your understanding

Does justify-content create space if the items already consume all available width?

<Accordion title="Check your answer">

It distributes available free space; it cannot invent room when there is none. Wrapping, sizing, and sensible labels resolve limited space.

</Accordion>
