## Before you begin

Complete the Beginner CSS project. You should be able to explain selectors, the cascade, the box model, readable typography, and colour choices.

Copy your previous portfolio folder before starting. The [practice pack](/assets/css/css-practice-pack.zip) includes a semantic HTML portfolio if you need a common starting point, plus isolated runnable lesson examples. Use local files; no account, API key, external font, or paid tool is required.

## Your learning outcomes and module order

### Flexible page layouts

Add wrapping navigation and a project-card grid to the portfolio. Begin with a single-column page and introduce a wider content/sidebar layout only when there is space.

- [Arrange navigation with Flexbox](/web-development/frontend/css/intermediate/i01-flexbox-for-navigation)
- [Build a project grid](/web-development/frontend/css/intermediate/i02-grid-for-projects)
- [Adapt layouts with media queries](/web-development/frontend/css/intermediate/i03-mobile-first-media-queries)
- [Module checkpoint](/web-development/frontend/css/intermediate/checkpoint-responsive-layout)
### Fluid content and positioning

Add a bounded fluid heading, a fully visible learning diagram, and a small positioned badge. Provide space for the badge and keep any table scrolling local to its wrapper.

- [Use fluid sizing with limits](/web-development/frontend/css/intermediate/i04-fluid-spacing-and-type)
- [Fit images and media without distortion](/web-development/frontend/css/intermediate/i05-images-and-responsive-media)
- [Position small details deliberately](/web-development/frontend/css/intermediate/i06-positioning-and-stacking)
- [Module checkpoint](/web-development/frontend/css/intermediate/checkpoint-fluid-content)
### Usable components and debugging

Style the existing contact form and reusable cards using shared custom properties. Provide visible focus and test the form with fictional invalid and valid entries. Reproduce and repair one responsive defect.

- [Style focus, links, and form controls](/web-development/frontend/css/intermediate/i07-interaction-states-and-forms)
- [Reuse design values with custom properties](/web-development/frontend/css/intermediate/i08-custom-properties)
- [Debug responsive layouts systematically](/web-development/frontend/css/intermediate/i09-debug-responsive-layouts)
- [Module checkpoint](/web-development/frontend/css/intermediate/checkpoint-component-review)
