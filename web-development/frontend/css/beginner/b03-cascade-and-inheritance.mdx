## Understand the idea

More than one declaration can affect an element. The cascade chooses a winner using factors including origin, importance, layers, specificity, and order. For this lesson all rules are ordinary author rules in the same layer: a class selector is more specific than a type selector, and equally specific rules are resolved by later source order.

Some properties, including color and font-family, are inherited from ancestors when no directly applicable value replaces them. Others, such as border and padding, are not inherited by default. A direct p rule wins over a colour merely inherited from body; this is not a competition between the specificity of body and p.

Avoid treating `!important` as a routine fix. First find the matching rule and remove or narrow the unintended conflict. Advanced lessons introduce cascade layers.

## Worked example

### HTML body

```html
<h1>My study notes</h1>
<p class="intro">A paragraph with two competing rules.</p>
<p>A normal paragraph.</p>
```

### styles.css

```css
body { color: #202124; font-family: sans-serif; }
p { color: #174ea6; }
.intro { color: #137333; }
.intro { color: #8e24aa; }
```

<Tip>CSS examples belong in your practice project's stylesheet. They are displayed as code here; copying them into an MDX page does not style your practice HTML.</Tip>

## Try it and observe

The intro is purple because the later equally specific class rule wins. Inspect its crossed-out rules. Remove the final rule and reload: the intro becomes green, while the ordinary paragraph stays blue.

## Practice challenge

Make the intro green and ordinary paragraphs blue, with no duplicate .intro colour rule and no !important. Explain which property both paragraphs inherit.

Save your changes, reload, and compare the observed result with your prediction. Keep a short note of what changed and why.

## Check your understanding

Does the last rule always win?

<Accordion title="Check your answer">

No. Source order resolves ties after earlier cascade decisions. In this simplified example equal class selectors tie in specificity; a later type selector would not override the class colour merely by being later.
