## Understand the idea

Each element has a content area, padding inside its border, a border, and margin outside. By default, width usually specifies the content box; padding and borders add to the rendered width. With `box-sizing: border-box`, the specified width includes padding and borders, but not margin.

The universal selector `*` selects all elements. Include pseudo-elements in a box-sizing reset so later decorations follow the same rule. Padding shorthand with two values sets vertical then horizontal space. Margin can separate blocks, but adjoining vertical margins in normal block flow can collapse; do not assume they always add together.

Use the DevTools box-model diagram to see measured values. Avoid repeated br elements or spaces as a layout mechanism.

## Worked example

### HTML body

```html
<h1>Practice card</h1>
<article class="card"><h2>My first project</h2><p>A simple portfolio.</p></article>
```

### styles.css

```css
*, *::before, *::after { box-sizing: border-box; }
.card { width: 280px; padding: 20px; border: 4px solid #174ea6; margin: 24px 0; }
```

<Tip>CSS examples belong in your practice project's stylesheet. They are displayed as code here; copying them into an MDX page does not style your practice HTML.</Tip>

## Try it and observe

With border-box the outside border width is 280px and the content area is 232px. Temporarily disable box-sizing: the box becomes 328px wide. Restore the reset before continuing.

## Practice challenge

Make the card’s border box 300px wide, padding 16px, border 2px, and outside vertical margin 24px. Keep the HTML unchanged.

Save your changes, reload, and compare the observed result with your prediction. Keep a short note of what changed and why.
