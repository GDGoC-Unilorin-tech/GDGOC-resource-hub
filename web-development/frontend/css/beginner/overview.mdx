## Before you begin

You should already be able to create an HTML document, link pages, add semantic regions, and build labelled forms. Complete the HTML course first if those tasks are unfamiliar. No CSS experience is required.

Copy your previous portfolio folder before starting. The [practice pack](/assets/css/css-practice-pack.zip) includes a semantic HTML portfolio if you need a common starting point, plus isolated runnable lesson examples. Use local files; no account, API key, external font, or paid tool is required.

## Your learning outcomes and module order

### Writing and understanding CSS

Style a profile introduction with an external stylesheet. Use a reusable card class and explain which declaration wins when two rules compete. Keep the CSS file separate from HTML.

- [Connect your first stylesheet](/web-development/frontend/css/beginner/b01-connect-a-stylesheet)
- [Select elements with reusable classes](/web-development/frontend/css/beginner/b02-selectors-and-classes)
- [Understand the cascade and inheritance](/web-development/frontend/css/beginner/b03-cascade-and-inheritance)
- [Module checkpoint](/web-development/frontend/css/beginner/checkpoint-css-foundations)
### Sizing and readable text

Build a reading panel with border-box sizing, flexible width capped at 40rem, readable system typography, and a clear heading hierarchy. Test longer text and 200% zoom.

- [Use the box model and predictable spacing](/web-development/frontend/css/beginner/b04-box-model-and-spacing)
- [Choose units and flexible widths](/web-development/frontend/css/beginner/b05-units-and-sizing)
- [Build readable typography](/web-development/frontend/css/beginner/b06-readable-typography)
- [Module checkpoint](/web-development/frontend/css/beginner/checkpoint-readable-layout)
### Colour and dependable presentation

Style a project card and a status notice with readable colour pairs, modest decoration, and a long identifier that wraps. Keep the status words and all project content in HTML.

- [Use colour with sufficient contrast](/web-development/frontend/css/beginner/b07-colour-and-contrast)
- [Separate decoration from content](/web-development/frontend/css/beginner/b08-borders-backgrounds-and-decoration)
- [Understand flow, display, and overflow](/web-development/frontend/css/beginner/b09-flow-display-and-overflow)
- [Module checkpoint](/web-development/frontend/css/beginner/checkpoint-visual-foundations)

## Stage project

Build **Readable portfolio styling** by combining the modules in the [stage project](/web-development/frontend/css/beginner/project). Keep the same HTML portfolio so your progress remains visible across HTML, CSS, and later JavaScript.
