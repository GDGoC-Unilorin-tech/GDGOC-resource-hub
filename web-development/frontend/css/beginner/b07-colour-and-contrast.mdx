## What you will learn

- Set foreground and background as a pair.
- Check text contrast with browser tools.
- Communicate meaning with more than colour.

## Understand the idea

Text colour is evaluated against the background it actually appears on. Hex notation such as #202124 gives red, green, and blue components. Transparent colours blend with whatever is beneath them, so a colour value alone cannot establish contrast.

For ordinary text, aim for at least a 4.5:1 contrast ratio; large text has a 3:1 threshold. Use 4.5:1 as the simple target for all text in this course. Meaningful control boundaries and graphical indicators also need adequate contrast. Inspect text in DevTools and use the colour picker’s contrast information when available; record the foreground/background pair and measured ratio.

Do not use red or green alone to identify an error or success. Visible wording such as “Needs revision” conveys the status even without colour. A high contrast result does not replace keyboard and content checks.

## Worked example

### HTML body

```html
<h1>Practice status</h1>
<p class="notice">Needs revision: give every image a useful text alternative.</p>
<p><a href="#help">Read the review guidance</a></p><p id="help">Check the purpose of each image.</p>
```

### styles.css

```css
body { color: #202124; background: #ffffff; }
a { color: #174ea6; }
.notice { color: #202124; background: #e8f0fe; padding: 1rem; }
```

## Try it and observe

Inspect the notice colour and background. Measure their contrast and the link against white. Imagine the page in greyscale: the status wording still communicates the issue.

## Practice challenge

Add a 4px solid #174ea6 left border to the notice. Keep its explicit status text, readable colours, and the underlined link. Record contrast for both text pairs.

Save your changes, reload, and compare the observed result with your prediction. Keep a short note of what changed and why.

<Accordion title="Need a hint?">

A border can reinforce a message, but it must not replace the words that explain it.

</Accordion>
