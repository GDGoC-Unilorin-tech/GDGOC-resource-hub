## Understand the idea

Normal flow places block boxes one after another and inline content within text lines. Inline-block allows an element to flow with text while accepting box dimensions and padding. Display changes layout behaviour, not the element’s semantics: a link remains a link.

Long unbroken text can overflow a narrow container. `overflow-wrap: anywhere` permits breaks when needed. An oversized image or fixed-width child needs a sizing fix instead. Do not apply overflow:hidden to the whole page to conceal the symptom: that can cut off content and focus indicators.

Display:none removes an element from layout and normally from the accessibility tree. Visibility:hidden also hides it but preserves its layout space. Neither is a way to retain useful information for everyone while only making it less prominent.

## Worked example

### HTML body

```html
<h1>Contact links</h1>
<div class="panel"><a class="badge" href="#notes">HTML learner</a><p>averylongunbrokensampleprojectidentifierthatshouldwrapratherthanclip</p></div><p id="notes">Keep every link readable.</p>
```

### styles.css

```css
.panel { max-width: 18rem; border: 1px solid #747775; padding: 1rem; }
.badge { display: inline-block; padding: 0.5rem; border: 1px solid currentColor; }
.panel p { overflow-wrap: anywhere; }
```

## Try it and observe

Inspect the long word at a narrow width. Disable overflow-wrap to reproduce the overflow. Restore it, then Tab to the badge and confirm its focus ring is not clipped.

## Practice challenge

Save your changes, reload, and compare the observed result with your prediction. Keep a short note of what changed and why.
