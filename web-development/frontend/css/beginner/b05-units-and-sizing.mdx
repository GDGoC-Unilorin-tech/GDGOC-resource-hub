## What you will learn

- Compare px, rem, percentages, and max-width.
- Keep a readable container within its parent.
- Avoid fixed heights for growing text.

## Understand the idea

Pixels express CSS pixel lengths, not a promise about physical device pixels. Rem units are relative to the root font size. Percentages depend on the property and its reference; a width percentage normally refers to the containing block’s width. Em units are context-dependent: for font-size they relate to the parent’s font size, while many other em lengths use the element’s own font size.

Pair a flexible width with a maximum to let a reading column shrink on small screens and stop growing on large ones. Auto horizontal margins centre a narrower block. Keep the browser’s root font setting rather than forcing a tiny root size.

Text grows when content changes or users zoom. Prefer content-driven height and use min-height only when a minimum is useful.

## Worked example

### HTML body

```html
<main class="reading"><h1>My learning story</h1><p>I practise a little every day and keep notes about what I discover.</p></main>
```

### styles.css

```css
* { box-sizing: border-box; }
.reading { width: 90%; max-width: 48rem; margin: 0 auto; padding: 1rem; }
```

<Tip>CSS examples belong in your practice project's stylesheet. They are displayed as code here; copying them into an MDX page does not style your practice HTML.</Tip>

## Try it and observe

Resize the window and watch the reading block shrink. At a sufficiently wide width it stops at 48rem. Increase text size: content should grow vertically instead of being clipped.

## Practice challenge

Change the reading column to 92% width with a 40rem maximum and 1.5rem padding. Keep it centred and allow any amount of text.

Save your changes, reload, and compare the observed result with your prediction. Keep a short note of what changed and why.

Why combine a percentage width with max-width?
