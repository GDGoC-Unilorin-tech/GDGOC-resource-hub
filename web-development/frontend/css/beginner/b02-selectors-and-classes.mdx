## What you will learn

- Distinguish type, class, and descendant selectors.
- Apply one class to several elements.
- Keep selectors focused on their intended content.

## Understand the idea

A type selector such as p matches all paragraphs. A class selector starts with a dot: `.intro` matches an element whose class attribute includes intro. HTML uses `class="intro"`, without the dot. Multiple elements can share a class, and an element can have several space-separated classes.

`.card p` matches paragraphs anywhere inside a card; `.card > p` matches only direct children. A comma creates a selector list, such as `h1, h2`. An ID selector starts with # and matches a unique document ID. Use classes for reusable styling rather than assigning IDs just to make a rule stronger.

Choose names that explain purpose, such as project-card, instead of names tied to a temporary colour.

## Worked example

### HTML body

```html
<h1>Projects</h1>
<p class="intro">My latest practice.</p>
<article class="card"><h2>HTML portfolio</h2><p>Connected pages.</p></article>
<p>This paragraph is outside the card.</p>
```

### styles.css

```css
.intro { font-size: 1.25rem; }
.card { border: 2px solid #174ea6; }
.card p { color: #174ea6; }
```

## Try it and observe

Inspect both paragraphs. Only the card paragraph receives the blue rule. Duplicate the card in HTML: the same class styles both without a new CSS rule.

## Practice challenge

Give every card 16px of inner spacing, make its h2 dark green, and leave the outside paragraph unchanged. Keep the intro enlarged.

Save your changes, reload, and compare the observed result with your prediction. Keep a short note of what changed and why.

<Accordion title="Need a hint?">

Use .card h2 to select headings inside cards. Padding supplies inner spacing; the box-model lesson explains it further.

</Accordion>

## Check your understanding

What is the difference between `.card p` and `.card, p`?

<Accordion title="Check your answer">

The space expresses a descendant relationship. The comma selects every card and every paragraph independently, including paragraphs outside cards.
