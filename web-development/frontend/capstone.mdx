<Info>This is the proposed capstone framework. The final brief and assessment rubric are still being developed.</Info>

## Purpose

Demonstrate that you can combine HTML structure, CSS responsive design, and JavaScript behaviour in a complete website. Framework use is not yet a requirement.

## Proposed milestones

1. Define the audience, problem, pages, and success criteria.
2. Build meaningful HTML structure and content.
3. Add responsive styling.
4. Implement useful interactions.
5. Check accessibility, keyboard operation, and expected behaviour.
6. Document the work and deploy the site.
7. Demonstrate the result and explain your decisions.

The proposal is to develop a project across the core courses, then extend and independently review it for the capstone. The shared project brief still needs team agreement; existing HTML projects remain unchanged.

## Evidence for review

- A source repository with setup instructions.
- A working deployed website.
- A record of checks, fixes, and known limitations.
- A short demonstration explaining implementation decisions.
