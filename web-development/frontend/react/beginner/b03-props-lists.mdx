## Understand the idea

Props are inputs from a parent. Read them without changing them. Render a collection by mapping data to elements and give each sibling a stable key from its data, such as a project ID. An array position is a poor identity when the list can reorder or filter.

The course dataset contains unique id, title, and category fields. In Beginner.jsx, create the component below and use it inside the list. The key belongs where the list is created, not inside the card. Avoid mutating an object passed as a prop; request a change through a callback or update state in its owner.

## Worked example

```jsx
function ProjectCard({ project }) {
  return <article className="card">
    <h3>{project.title}</h3>
    <p>{project.category}</p>
  </article>;
}
// Inside the parent return:
// projects.map(project => <ProjectCard key={project.id} project={project} />)
```
