## What you will learn

Compose semantic UI from small, named components.

## Before you begin

Work through the previous page and use the extracted practice pack. Keep changes in your own practice branch.

## Understand the idea

Use a capitalised component name so JSX treats it as your function rather than a built-in HTML tag. Return one enclosing tree or a fragment. Close every JSX tag, use className for CSS classes, and put JavaScript expressions inside braces.

In src/Beginner.jsx, extract a Profile component above the default Beginner function, then render `<Profile />` before its project list. Keep the component at module scope; declaring components inside other components can cause state to reset when their identity changes. JSX does not replace accessible HTML: a button still performs an action and an anchor still navigates.

## Worked example

```jsx
function Profile() {
  const name = 'Amina';
  return <section className="card">
    <h3>{name}'s portfolio</h3>
    <p>I build useful web interfaces.</p>
  </section>;
}
```

## Practice challenge
