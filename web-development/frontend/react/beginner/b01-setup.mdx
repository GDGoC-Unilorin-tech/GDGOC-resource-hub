## Before you begin

Work through the previous page and use the extracted practice pack. Keep changes in your own practice branch.

## Understand the idea

React describes UI using components. A component is a function that returns UI descriptions; React updates the DOM when its inputs change. HTML semantics and CSS still matter. JSX is a syntax extension processed by the build tool, not a new browser language.

Extract the [React practice pack](/assets/react/react-practice-pack.zip) outside the hub repository. Use a supported Node.js runtime (this pack requires Node 22.12 or newer). In the extracted root run `npm ci`, then `npm run dev`. Open the address printed by Vite. Stop with Ctrl+C. The first install needs network access. This pack uses JavaScript and Vite for learning client-side React; it is not a server-rendered framework.

Open Projects in the app navigation, then use the Worked example stage selector to choose Beginner. Intermediate and Advanced are available in the same selector. Find `src/main.jsx`, which mounts the app in the element named root in index.html. Editing a component updates the preview; save changes in your editor, not only in DevTools.

## Worked example

```jsx
import { StrictMode } from 'react';
import { createRoot } from 'react-dom/client';
import App from './App.jsx';
createRoot(document.getElementById('root')).render(
  <StrictMode><App /></StrictMode>
);
```
