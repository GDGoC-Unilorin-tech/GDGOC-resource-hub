## Understand the idea

A reducer computes new state from previous state and an action. It is useful when related updates need a clear vocabulary. It is not automatically better than useState for a single value. Keep reducers pure: no requests, mutation, time-dependent values, or storage writes inside them.

The Advanced example uses filtersReducer in logic.js. Search, category, sort, and reset actions describe intent. Returning a new object preserves React's update model and makes the reducer straightforward to test.

## Worked example

```jsx
export function filtersReducer(state, action) {
  switch (action.type) {
    case 'query': return { ...state, query: action.value };
    case 'category': return { ...state, category: action.value };
    case 'sort': return { ...state, sort: action.value };
    case 'reset': return { query: '', category: 'all', sort: 'original' };
    default: return state;
  }
}
```
