## What you will learn

Keep input state and feedback aligned.

## Before you begin

Work through the previous page and use the extracted practice pack. Keep changes in your own practice branch.

## Understand the idea

A controlled input receives its value from state and updates that state onChange. Start a text field with an empty string, not undefined. Associate every input with a label. Form submission is an event; prevent the browser navigation when the app handles it locally.

The Intermediate example's query field filters project titles. Below it, add a small practice note form with local feedback. It is not a message-delivery service. Validate trimmed content and retain invalid input so the learner can correct it. Do not claim a message was sent when nothing was delivered.

## Worked example

```jsx
const [note, setNote] = useState('');
const [feedback, setFeedback] = useState('');
function submit(event) {
  event.preventDefault();
  setFeedback(note.trim() ? 'Practice note accepted locally.' : 'Enter a note.');
}
// <form onSubmit={submit}><label htmlFor="note">Practice note</label>
// <input id="note" value={note} onChange={e => setNote(e.target.value)} />
// <button>Check note</button><p role="status">{feedback}</p></form>
```
