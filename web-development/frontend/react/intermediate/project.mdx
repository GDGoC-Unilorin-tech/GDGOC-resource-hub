## Project brief

Load validated project data, combine query/category/sort, provide reset and retry, and support Home/Projects/About hash navigation and browser Back.

Personalise the project titles and descriptions. Retain semantic HTML and the responsive design skills from the CSS course. This stage assesses React behaviour; a copied sample without explanation does not demonstrate understanding.

## Build and review

1. Sketch component responsibilities and state ownership.
2. Implement one requirement at a time and verify it.
3. Check at 320px and desktop width, then complete a keyboard journey.
4. Record errors, fixes, retests, and what remains untested.

## Completion checklist

- [ ] All requirements in the brief are demonstrated.
- [ ] Stable IDs identify list entries.
- [ ] Controls have meaningful labels and visible focus.
- [ ] Empty/error states provide an appropriate recovery action.
- [ ] My review record describes actual results.

<Accordion title="Hints">
Begin with the smallest state model that represents the requirements. Derive result counts and filtered arrays. Do not add Effects for calculations that can run during render.
</Accordion>
