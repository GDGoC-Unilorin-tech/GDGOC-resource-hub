The React lessons are taught inside this hub. These Google-affiliated resources support testing, accessibility, debugging, and hosting; they are not presented as an official Google React curriculum.

| Need | Reference |
| --- | --- |
| Testing concepts and component exercises | [web.dev Learn Testing](https://web.dev/learn/testing) |
| Accessible UI | [web.dev Learn Accessibility](https://web.dev/learn/accessibility) |
| JavaScript review | [web.dev Learn JavaScript](https://web.dev/learn/javascript) |
| Browser debugging | [Chrome DevTools](https://developer.chrome.com/docs/devtools) |
| Performance investigation | [Chrome Performance panel](https://developer.chrome.com/docs/devtools/performance) |
| Static Hosting | [Firebase Hosting quickstart](https://firebase.google.com/docs/hosting/quickstart) |
| Preview and release workflow | [Firebase test, preview, and deploy](https://firebase.google.com/docs/hosting/test-preview-deploy) |

React, Vite, and npm are separate tools used to run the exercises. Installing their packages is part of setup; it does not make them Google products.
