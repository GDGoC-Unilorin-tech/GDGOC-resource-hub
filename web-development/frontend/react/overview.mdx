## Before you begin

Build a foundation in [HTML](/web-development/frontend/html/overview),
[CSS](/web-development/frontend/css/overview), and
[JavaScript](/web-development/frontend/javascript/overview).
Practise functions, arrays, objects, modules, DOM events, and asynchronous code before starting this course.

## Planned learning journey

- **Beginner:** Core concepts, guided examples, topic practice, and a first project.
- **Intermediate:** Build larger interfaces, manage data, and complete practical checkpoints.
- **Advanced:** Review reliability, accessibility, testing, and performance.
- **Final building challenge:** Apply your skills in an independent project with a completion checklist.
- **Further learning:** Curated Google resources for continuing beyond the course.

Every lesson will include objectives, examples, practice, hints, and a separate suggested solution.
