## Your learning journey

Continue your HTML, CSS, JavaScript, and [workflow](/web-development/frontend/tools-and-workflow) learning by rebuilding a portfolio explorer in React. This is a client-side React foundations course. It does not cover server components, full-stack frameworks, authentication, or databases.

Complete JavaScript functions, arrays, objects, modules, events, and async work before starting. You should be able to explain the existing [JavaScript final project](/web-development/frontend/javascript/final-project). React and Vite are independent tools, not Google products. All external learner references remain Google-affiliated and supplement the internal lessons.

| Stage | Skills | Project |
| --- | --- | --- |
| Beginner | JSX, components, props, lists, events, state | Saved-project cards |
| Intermediate | Forms, shared state, requests, hash navigation, recovery | Searchable portfolio explorer |
| Advanced | Reducers, custom Hooks, focus, tests, production build | Reviewed React portfolio |

[Download the React practice pack](/assets/react/react-practice-pack.zip). It contains a locked dependency set, three runnable worked stages, pure-function tests, and a review template. Read README.md and attempt exercises before studying the worked implementations. Lesson snippets show changes to named components, not unrelated standalone applications.

<Note>Completion is assessed through checklists and demonstrated work. There are no automated stage locks or progress accounts. Hosting practice requires your own account.</Note>
