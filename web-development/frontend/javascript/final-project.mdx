<Info>This is the project direction, not a ready-to-complete assessment. The full brief and worked solution will follow the remaining course modules.</Info>

## Intended outcome

Extend your existing HTML/CSS portfolio with a project explorer that lets visitors search or filter work, remembers a non-sensitive preference, and handles data-loading failures clearly.

## Planned completion evidence

- Working source files with clear setup instructions.
- An explanation of functions, state, events, and data flow.
- Keyboard-operable controls and meaningful feedback.
- Recorded checks for normal, empty, invalid, and failed states.
- A short demonstration and a list of known limitations.

The final brief will include concrete requirements, optional hints, a completion checklist, and a separate suggested implementation. This JavaScript challenge prepares learners for the wider frontend capstone; it does not automatically grant contribution or production access.
