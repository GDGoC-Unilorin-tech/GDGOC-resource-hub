JavaScript adds programmable behaviour to your HTML and CSS. This course takes you from your first script to a modular project explorer with search, filtering, saved preferences, reliable data loading, and tests.

## What is available

All three levels are available: **31 topic lessons, 9 module checkpoints, 3 stage projects, and a final building challenge**. Each topic includes examples, practice, a checklist, hints, and a separate suggested solution. Stage projects and the final challenge include complete downloadable implementations.

## Before you begin

You should be able to create and open an HTML file. No previous programming experience is required for Beginner. Basic CSS helps when integrating the project into your portfolio, but our practice pages include their own minimal HTML. Use your existing text editor and a browser with developer tools.

Beginner scripts can run from local files. Intermediate introduces a local HTTP server before fetch; Advanced modules also use that server. No paid account, cloud service, API key, Node.js installation, or package manager is required by the worked projects.

## Your learning journey

| Level | Learn | Build |
| --- | --- | --- |
| Beginner | Values, decisions, functions, scope, arrays, objects, loops, DOM, and events | A portfolio project-category filter |
| Intermediate | Data transformation, forms, JSON, storage, promises, fetch, and failure states | A searchable project explorer |
| Advanced | Modules, closures, pure functions, delegation, request races, testing, and performance review | A reliable modular explorer |
| Final challenge | Integrate and demonstrate your skills | A portfolio explorer with sorting, reset, tests, and review evidence |

Use a separate practice folder, then integrate into a copy or branch of your portfolio. Coordinate with the HTML/CSS collaborators before changing their shared files. React, Next.js, backend services, and deployment belong to follow-on courses.

## How to complete the course

1. Predict the output, run each example, and change an input.
2. Attempt practice before opening its hint or solution.
3. Complete each module checkpoint independently.
4. Build the stage project and record checks and repairs.
5. Complete the final challenge and demonstrate your choices.

<Note>Checklists guide self-assessment. The hub does not automatically grade work, save course progress, or lock stages. A reviewer can assess your evidence separately.</Note>
