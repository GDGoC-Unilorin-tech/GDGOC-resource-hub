JavaScript lets a web page respond to actions, work with data, and update its content. You will learn the language before using it to build interactive pages.

<Note>The first Beginner module, Programming foundations, is available with four lessons and a checkpoint. Remaining Beginner modules, later levels, and projects are planned. This is an expanding course, not a completed JavaScript track.</Note>

## Before you begin

You do not need previous programming experience. You should already be able to create an HTML file, use headings and links, and open it in a browser. Basic CSS will help when we reach interface work; styling is not required for the first module.

Use a computer, a browser with developer tools, and the text editor you used for HTML. Examples explain Chrome's developer tools. No Node.js, framework, package manager, paid account, or API key is needed for the first module.

## What you will build towards

| Stage | Skills to demonstrate | Portfolio milestone |
| --- | --- | --- |
| Beginner | Values, decisions, functions, collections, DOM updates, and events | A project list with a working filter and useful status text |
| Intermediate | Forms, data transformations, saved preferences, asynchronous requests, and error states | A searchable project explorer with saved preferences and a local JSON data file |
| Advanced | Modules, closures, event delegation, testing, accessible feedback, and resilient behaviour | A modular, tested portfolio feature that handles failure gracefully |
| Final challenge | Combine and explain the skills above | An interactive portfolio with a documented demonstration and test evidence |

Keep your HTML/CSS portfolio as the foundation for later stages. The first lessons use a separate practice folder so you can experiment without breaking it. Frameworks such as React and Next.js follow language and browser fundamentals.

## How to learn here

1. Read the explanation and predict the example's output.
2. Run the example, change one value, and explain the result.
3. Attempt the challenge before opening the hint or suggested solution.
4. Check your work against the checklist.
5. Complete each module checkpoint independently and keep evidence.
6. Complete each stage project when its lessons are available.

<Info>Completion is self-assessed unless a reviewer checks your work. There is no automatic grading, saved course progress, or enforced stage locking.</Info>
