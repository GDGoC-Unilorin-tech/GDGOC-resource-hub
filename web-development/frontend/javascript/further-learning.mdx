Our lessons teach the core material inside the hub. These optional Google resources support review and further study. The linked learning articles are free to read; they are not prerequisites for completing the first module.

## Language foundations

- [web.dev: Learn JavaScript](https://web.dev/learn/javascript) — Explore Google's course on language fundamentals, including variables, functions, objects, and collections.
- [web.dev: Data types and structures](https://web.dev/learn/javascript/data-types) — Review JavaScript's primitive value types.
- [web.dev: Comparison operators](https://web.dev/learn/javascript/comparison) — Investigate equality and comparison behaviour beyond the initial exercises.

## Browser tools

- [Chrome DevTools: Run JavaScript in the Console](https://developer.chrome.com/docs/devtools/console/javascript) — Practise evaluating JavaScript in the browser.
- [Chrome DevTools: Debug JavaScript](https://developer.chrome.com/docs/devtools/javascript) — Learn to pause execution and investigate problems as your programs grow.

The course examples and challenges are written for this hub. These links are further-reading references, not a claim that Google authored or certified our course.
