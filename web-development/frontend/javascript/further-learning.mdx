The core course is taught inside this hub. Use these free-to-read Google articles and courses for review and deeper study after the final challenge.

## Language and browser foundations

- [web.dev: Learn JavaScript](https://web.dev/learn/javascript) — Explore the language, functions, objects, and collections.
- [Chrome DevTools: Debug JavaScript](https://developer.chrome.com/docs/devtools/javascript) — Investigate execution with breakpoints and browser tools.

## Forms and asynchronous interfaces

- [web.dev: Learn Forms](https://web.dev/learn/forms) — Review usable form controls, validation, and accessibility.
- [web.dev: Fetch API error handling](https://web.dev/articles/fetch-api-error-handling) — Explore failure scenarios and recovery behaviour.

## Testing and performance

- [web.dev: Learn Testing](https://web.dev/learn/testing) — Extend the small checks in this course into a broader testing approach.
- [web.dev: Optimize long tasks](https://web.dev/articles/optimize-long-tasks) — Understand main-thread work and responsiveness.

These are references, not a claim that Google authored or certified the hub's course. Keep your project files and review evidence for the frontend capstone and future contribution discussions.
