## Understand the idea

A closure is a function together with access to the surrounding lexical scope where it was created. A returned function can keep using a local variable after the outer call has finished. Separate calls to the outer function create independent local state.

Closures are useful for a counter or a small stateful helper. They are not a security mechanism: code running in the same application should still be treated according to its trust level. Keep the behaviour explicit and avoid hidden state when a plain function would be clearer.

## Run the example

```javascript
function createCounter() {
  let count = 0;
  return function increment() {
    count = count + 1;
    return count;
  };
}
const first = createCounter();
const second = createCounter();
console.log(first());
console.log(first());
console.log(second());
```

**Expected result:** The independent counters print 1, 2, 1.
