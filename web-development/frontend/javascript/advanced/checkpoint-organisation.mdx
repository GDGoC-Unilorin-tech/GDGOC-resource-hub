## Task

Split a project-selection function into a module. Keep rendering in app.js and use a closure for a separate visit-only counter. Use object copies when updating a record. Serve the modules over HTTP.

Attempt the task without copying a full implementation. Refer back to individual lesson concepts when necessary. Keep this work in a separate practice folder.

## Completion criteria

- [ ] Imports resolve without global helper variables.
- [ ] Identical inputs produce identical selected titles.
- [ ] Changing a copied record does not change the original flat record.
- [ ] Two counters retain independent state.

## Evidence to keep

Keep your source files and a short record of each input/action, expected result, actual result, and repair. Explain one design choice and one error you investigated. A screenshot supports the record but does not replace runnable code.
