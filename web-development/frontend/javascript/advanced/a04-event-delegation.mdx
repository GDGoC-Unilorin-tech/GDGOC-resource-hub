## Understand the idea

Many events bubble from the target through its ancestors. A listener on a parent can handle clicks from children created later. `event.target` is where the event originated; `event.currentTarget` is the element whose listener is running.

`closest` finds a matching element at or above the target, so clicking text inside a span still finds its button. Confirm that the result belongs to the intended container. `dataset.category` reads the `data-category` attribute as text. Validate allowed actions rather than trusting arbitrary attributes.

## Run the example

```javascript
const filters = document.querySelector("#filters");
filters.addEventListener("click", event => {
  if (!(event.target instanceof Element)) return;
  const button = event.target.closest("button[data-category]");
  if (!button || !filters.contains(button)) return;
  const category = button.dataset.category;
  if (category !== "all" && category !== "web") return;
  document.querySelector("#status").textContent = `Category: ${category}`;
});
```

**Expected result:** Clicking the nested Web label reports Category: web; clicking empty container space does nothing.
