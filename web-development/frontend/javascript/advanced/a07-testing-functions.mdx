## Understand the idea

A test compares observed behaviour with an expectation and fails clearly if they differ. `console.assert` is useful while experimenting, but a throwing assertion is harder to overlook in a script. Choose cases that could reveal a defect: zero, an exact boundary, beyond the boundary, and empty input.

Tests do not prove a program has no bugs. Record assumptions about accepted inputs, and test side effects such as accidental mutation separately. Production test frameworks add runners and reporting; these small browser checks need no dependencies.

Reuse `math.js` from the first Advanced lesson for the example. The challenge is self-contained in app.js. `result += value` is shorthand for `result = result + value`.

## Run the example

```javascript
import { remaining } from "./math.js";
function equal(actual, expected, label) {
  if (actual !== expected) throw new Error(`${label}: expected ${expected}, got ${actual}`);
}
equal(remaining(30, 0), 30, "zero done");
equal(remaining(30, 30), 0, "exact target");
equal(remaining(30, 40), 0, "past target");
console.log("3 checks passed");
```

**Expected result:** All checks pass. Temporarily removing the clamp in math.js makes the past-target check fail.

## Practice challenge

Create a pure total function for an array of minutes. Test empty input, one item, and several items. Assert that the source array length and first value are unchanged.

### Completion checklist

- [ ] A deliberate wrong result triggers an error.
- [ ] All five checks pass after repair.
- [ ] Accepted input assumptions are recorded.

<Accordion title="Hint: plan your approach">

Use explicit failures, not just printed values. State that inputs are non-negative numbers.

</Accordion>

<Accordion title="Suggested solution: compare after trying">

Replace `app.js` with this complete solution and use the same HTML/setup above.

```javascript
function total(minutes) {
  let result = 0;
  for (const value of minutes) result += value;
  return result;
}
function equal(actual, expected, label) {
  if (actual !== expected) throw new Error(label);
}
const input = [10, 20];
equal(total([]), 0, "empty");
equal(total([5]), 5, "single");
equal(total(input), 30, "multiple");
equal(input.length, 2, "length unchanged");
equal(input[0], 10, "first unchanged");
console.log("5 checks passed");
```

Explain why it meets each checklist item. Different implementations can be correct.
