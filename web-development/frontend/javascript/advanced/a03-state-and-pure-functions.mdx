## Understand the idea

A pure function calculates its output from its inputs without observable side effects such as storage writes, DOM changes, or modifying the inputs. This makes test results easier to reproduce. Keep state updates and rendering explicit around those calculations.

Objects are compared by identity, not by matching fields. Two separately created objects are different even if their contents match. Spreading an array copies the array, but its object entries still refer to the same objects. To update one flat record safely, create a new array and a new object for that record.

## Run the example

```javascript
const projects = [{ id: "profile", complete: false }];
function markComplete(items, id) {
  return items.map(item => item.id === id ? { ...item, complete: true } : item);
}
const updated = markComplete(projects, "profile");
console.log(projects[0].complete);
console.log(updated[0].complete);
console.log(projects[0] === updated[0]);
```

**Expected result:** Output is false, true, false.
