## Understand the idea

Use performance.now for elapsed time, and the DevTools Performance panel to inspect long tasks. A fast result on your computer may still be slow on another device. Record the input size, device or throttling setting, and repeatable action.

Split independent work into batches when needed. Awaiting a timer gives the browser an opportunity to handle other tasks between batches; it does not guarantee a particular frame rate. Do not add batching to tiny calculations without evidence.

The three-part loop `for (let batch = 0; batch < 10; batch++)` initialises a counter, checks the condition before each iteration, and increments it afterward.

## Run the example

```javascript
function pause() {
  return new Promise(resolve => setTimeout(resolve, 0));
}
document.querySelector("#run").addEventListener("click", async event => {
  const button = event.currentTarget;
  button.disabled = true;
  const start = performance.now();
  let total = 0;
  for (let batch = 0; batch < 10; batch++) {
    for (let item = 0; item < 1000; item++) total++;
    document.querySelector("#status").textContent = `Processed ${total}`;
    await pause();
  }
  console.log(`Elapsed milliseconds: ${performance.now() - start}`);
  button.disabled = false;
});
```

**Expected result:** The final count is 10000. Elapsed time varies; it is not a fixed expected number.

## Practice challenge

Process 5000 items in five batches. Restore the button in finally even if the work fails. Record a manual regression checklist for normal, repeated, and keyboard activation.

### Completion checklist

- [ ] The final result is 5000.
- [ ] Repeated runs do not accumulate old totals.
- [ ] The button becomes usable after completion.
- [ ] My audit records an action, expected/actual result, and environment.

```javascript
const button = document.querySelector("#run");
const status = document.querySelector("#status");
button.addEventListener("click", async () => {
  button.disabled = true;

    for (let batch = 0; batch < 5; batch++) {
      for (let item = 0; item < 1000; item++) total++;
      status.textContent = `Processed ${total}`;
      await new Promise(resolve => setTimeout(resolve, 0));

  } catch (error) {

    button.disabled = false;
  }
});
```
