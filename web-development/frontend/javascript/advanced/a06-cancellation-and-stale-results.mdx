## Understand the idea

When requests overlap, an older one may finish last. Track a request number and apply results only if they belong to the newest request. `AbortController` can also cancel fetch: pass its signal in the options and call abort on the old controller.

Cancellation saves work where supported; the request-number check protects UI correctness. Keep old-request catch/finally handlers from changing the new request's UI. An intentional cancellation should not produce a misleading failure message.

Use the HTTP setup and `projects.json` from Intermediate. The first example logs to the console; the challenge uses the button and status paragraph.

## Run the example

```javascript
let currentRequest = 0;
function delayed(value, delay) {
  return new Promise(resolve => setTimeout(() => resolve(value), delay));
}
async function show(value, delay) {
  const request = ++currentRequest;
  const result = await delayed(value, delay);
  if (request !== currentRequest) return;
  console.log(result);
}
show("old", 40);
show("new", 5);
```

**Expected result:** Only new is printed even though old finishes later. ++ increments the counter before its value is used.

<Accordion title="Suggested solution: compare after trying">

Replace `app.js` with this complete solution and use the same HTML/setup above.

```javascript
let controller;
let currentRequest = 0;
document.querySelector("#load").addEventListener("click", async () => {
  if (controller) controller.abort();
  controller = new AbortController();
  const request = ++currentRequest;
  const status = document.querySelector("#status");
  status.textContent = "Loading…";
  try {
    const response = await fetch("./projects.json", { signal: controller.signal });
    if (!response.ok) throw new Error("HTTP failure");
    const data = await response.json();
    if (!Array.isArray(data)) throw new Error("Invalid data");
    if (request !== currentRequest) return;
    status.textContent = `${data.length} projects`;
  } catch (error) {
    if (request !== currentRequest || error.name === "AbortError") return;
    status.textContent = "Could not load projects. Try again.";
  }
});
```

Explain why it meets each checklist item. Different implementations can be correct.
