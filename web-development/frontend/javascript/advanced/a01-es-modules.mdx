## Understand the idea

Modules give each file its own scope and run in strict mode. `export` makes a declaration available to other modules; `import` names what another module needs. A relative import includes the file extension. Modules are deferred by default and must be served over HTTP for these exercises.

Keep calculations separate from code that queries the DOM. A calculation module can be reused and tested without a page. Avoid placing unrelated logic into one large file or triggering DOM updates just by importing a helper.

Create `math.js` beside `app.js`:

```javascript
export function remaining(target, done) {
  return done >= target ? 0 : target - done;
}
```

The code below belongs in `app.js`. Keep the HTTP server from Intermediate running.

## Run the example

```javascript
import { remaining } from "./math.js";
console.log(remaining(30, 10));
console.log(remaining(30, 40));
```

**Expected result:** The imported function prints 20 then 0.

## Practice challenge

Use the imported helper to print remaining minutes for (60, 15), (60, 60), and (60, 90). Keep the function in math.js and the calls in app.js.

### Completion checklist

- [ ] Output is 45, 0, 0.
- [ ] The helper exists in a separate module.
- [ ] The page uses type="module" and HTTP.

<Accordion title="Hint: plan your approach">
