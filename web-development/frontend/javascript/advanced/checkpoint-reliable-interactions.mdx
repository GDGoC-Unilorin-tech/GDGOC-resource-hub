## Task

Combine delegated category buttons with a reload control. Cancel superseded fetch requests, guard updates with a request number, and ignore intentional aborts. Demonstrate a slow first request followed by a faster second request.

Attempt the task without copying a full implementation. Refer back to individual lesson concepts when necessary. Keep this work in a separate practice folder.

## Completion criteria

- [ ] A nested button label triggers the right action.
- [ ] A newly appended allowed-category button works.
- [ ] The late first request cannot replace the second result.
- [ ] An actual failed latest request shows an error; cancellation alone does not.

## Evidence to keep

Keep your source files and a short record of each input/action, expected result, actual result, and repair. Explain one design choice and one error you investigated. A screenshot supports the record but does not replace runnable code.

<Accordion title="Hint">

Guard success and failure paths. A stale catch handler can corrupt the UI just as a stale success handler can.

</Accordion>
