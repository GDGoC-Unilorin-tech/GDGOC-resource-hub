## Prerequisites and outcomes

Complete the Intermediate work on data, forms, persistence, and asynchronous requests. Learn to organise a small application, reason about its state, test important behaviour, and improve accessibility and responsiveness.

| Module | Planned topics | Practical checkpoint |
| --- | --- | --- |
| Code organisation | ES modules; scope and closures; separating data, state, and rendering; object identity and mutation | Refactor a feature into modules without changing its behaviour |
| Reliable interactions | Event delegation; event-loop fundamentals; stale requests and cancellation; keyboard/focus behaviour; safe text rendering | Handle rapid interaction and failed requests without misleading results |
| Test and demonstrate | Pure-function checks; DOM interaction tests; browser debugging; performance measurements; regression checklist | Audit a feature, reproduce a defect, repair it, and document the result |

## Advanced portfolio milestone — planned

Refactor and audit the existing project explorer. Handle empty and malformed data, storage failure, and failed requests; retain useful content and accessible controls. Keep evidence of checks rather than relying only on a tool score.

Frameworks, backend services, and AI integrations are separate follow-on courses. This level focuses on dependable JavaScript and browser behaviour.
