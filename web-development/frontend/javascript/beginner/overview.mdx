## Your learning objectives

By the end of this planned level, you should be able to explain program output, organise simple data, reuse logic, and connect that logic to a page through the DOM and events.

## Module 1: Programming foundations — available

1. [Run your first JavaScript](/web-development/frontend/javascript/beginner/b01-run-your-first-javascript)
2. [Variables and values](/web-development/frontend/javascript/beginner/b02-variables-and-values)
3. [Expressions, numbers, and messages](/web-development/frontend/javascript/beginner/b03-expressions-and-messages)
4. [Comparisons and decisions](/web-development/frontend/javascript/beginner/b04-comparisons-and-decisions)
5. [Checkpoint: Learning-session summary](/web-development/frontend/javascript/beginner/checkpoint-programming-foundations)

**Demonstrate:** create and run a script that stores learning-session data, calculates progress, and chooses the right message.

## Module 2: Reusable logic and collections — planned

- Functions, parameters, and return values.
- Scope and local variables.
- Arrays and indexed access.
- Objects and properties.
- Loops and tracing repeated work.
- Checkpoint: summarise a collection of portfolio projects.

## Module 3: Your first interactive page — planned

- The DOM and selecting elements.
- Updating text and classes safely.
- Native buttons and event listeners.
- Debugging errors and tracing execution.
- Checkpoint: update a page in response to a keyboard-operable button.

## Beginner project — planned

Add a project-category filter to your portfolio. Keep the project content readable, use real buttons, and explain how each user action changes the visible result. The full brief, hints, checklist, and worked solution will follow the remaining Beginner lessons.
