## Expressions produce values

An expression is code that evaluates to a value. `10 + 5` evaluates to `15`; you can store that result in a variable or print it.

| Operator | Operation | Example result |
| --- | --- | --- |
| `+` | Addition | `8 + 2` gives `10` |
| `-` | Subtraction | `8 - 2` gives `6` |
| `*` | Multiplication | `8 * 2` gives `16` |
| `/` | Division | `8 / 2` gives `4` |
| `%` | Remainder | `9 % 2` gives `1` |

```javascript
const readingMinutes = 15;
const practiceMinutes = 25;
const totalMinutes = readingMinutes + practiceMinutes;
const targetMinutes = 60;
const remainingMinutes = targetMinutes - totalMinutes;

console.log(totalMinutes);
console.log(remainingMinutes);
console.log((10 + 5) * 2);
console.log(10 + 5 * 2);
```

Output: `40`, `20`, `30`, `20`. Multiplication runs before addition unless parentheses change the order. Name intermediate results so a reader can follow your calculation.

## Write a readable message

A template literal is text enclosed in backticks. Inside it, a dollar sign followed by braces marks an expression whose value is inserted into the message:

```javascript
const learnerName = "Amina";
const completedLessons = 3;
const totalLessons = 4;
const remainingLessons = totalLessons - completedLessons;

console.log(`${learnerName} completed ${completedLessons} of ${totalLessons} lessons.`);
console.log(`Remaining lessons: ${remainingLessons}`);
```

Expected output:

```text
Amina completed 3 of 4 lessons.
Remaining lessons: 1
```

The backtick character is different from the single quote. Ordinary quoted strings do not evaluate those placeholders.

## Numbers and text behave differently

```javascript
console.log(10 + 5);
console.log("10" + "5");
console.log("10" + 5);
```

The first line prints the number `15`. The others print the text `105`: `+` joins strings, and when one operand here is a string, the number is converted to text. Keep numeric data as numbers for these exercises. A later forms lesson will cover converting and checking user input.

<Note>JavaScript numbers can have rounding effects with decimal fractions. We use whole-number lesson counts and minutes here. Do not assume ordinary decimal arithmetic is suitable for exact financial calculations.</Note>
