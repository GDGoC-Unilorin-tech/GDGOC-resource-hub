## Understand the idea

A function names a reusable set of instructions. Defining it does not run its body; a call with parentheses runs it. Parameters are local names declared in the definition. Arguments are the actual values supplied by a call.

`return` sends a value back to the caller and ends that function call. Printing with `console.log` only displays something; it does not supply your function's result. A function that reaches its end without returning a value produces `undefined`.

## Run the example

```javascript
function remaining(total, done) {
  return total - done;
}
const result = remaining(8, 3);
console.log(result);
console.log(remaining(8, 8));
```

**Expected result:** The console prints `5`, then `0`.
