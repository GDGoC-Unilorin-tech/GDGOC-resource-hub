## Task

Create an array of three project objects with title, minutes, and complete fields. Write a function that returns total minutes for completed projects only. Keep the calculation separate from logging. Test an empty array and an array where no projects are complete.

Attempt the task without copying a full implementation. Refer back to individual lesson concepts when necessary. Keep this work in a separate practice folder.

## Completion criteria

- [ ] Use durations 10, 20, and 30 with only the first and third complete: the result is 40.
- [ ] An empty array and an all-incomplete array return 0.
- [ ] Input records remain unchanged.
- [ ] Explain the function parameters, loop, and accumulator scope.

## Evidence to keep

Keep your source files and a short record of each input/action, expected result, actual result, and repair. Explain one design choice and one error you investigated. A screenshot supports the record but does not replace runnable code.

<Accordion title="Hint">

Combine a loop with an if condition. Initialise the total once per function call.

</Accordion>
