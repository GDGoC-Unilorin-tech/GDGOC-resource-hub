## Task

Create a heading, status paragraph, Add session button, and Reset button. Add increments a counter; Reset sets it to zero. Initialise visible status from state. Use native buttons and textContent.

Attempt the task without copying a full implementation. Refer back to individual lesson concepts when necessary. Keep this work in a separate practice folder.

## Completion criteria

- [ ] Initial status shows 0.
- [ ] Three Add activations produce 3.
- [ ] Reset returns to 0; another Add produces 1.
- [ ] Keyboard activation works and no duplicate listeners accumulate.

## Evidence to keep

Keep your source files and a short record of each input/action, expected result, actual result, and repair. Explain one design choice and one error you investigated. A screenshot supports the record but does not replace runnable code.

<Accordion title="Hint">

Keep the count outside the handlers and use one render function for initial and later updates.

</Accordion>

Topic lessons supply worked examples; this checkpoint intentionally asks you to combine them independently rather than copy a complete answer. If a criterion fails, revisit the related lesson before moving on.

</Accordion>
