## Understand the idea

An array groups values in order using square brackets. Indexes start at zero: the first item is at index 0. `length` tells you how many items exist; the last index is one less than the length. Reading an index that does not exist gives `undefined`.

`push` is an array method: a function attached to the array that adds an item at the end. A `const` array name cannot be reassigned to another array, but the existing array's contents can change.

## Run the example

```javascript
const topics = ["HTML", "CSS"];
console.log(topics[0]);
topics.push("JavaScript");
console.log(topics.length);
console.log(topics[topics.length - 1]);
```

**Expected result:** The console prints `HTML`, `3`, and `JavaScript`.
