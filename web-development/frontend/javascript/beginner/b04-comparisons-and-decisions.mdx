## Compare values

| Operator | Question | Example |
| --- | --- | --- |
| `===` | Same type and equal value? | `3 === 3` gives `true` |
| `!==` | Different type or unequal value? | `3 !== "3"` gives `true` |
| `>` | Greater than? | `4 > 3` gives `true` |
| `<` | Less than? | `2 < 3` gives `true` |
| `>=` | Greater than or equal? | `3 >= 3` gives `true` |
| `<=` | Less than or equal? | `3 <= 3` gives `true` |

These examples compare primitive values. Object comparisons come later. Use numbers for the duration comparisons in this lesson.

```javascript
console.log(3 === 3);
console.log("3" === 3);
console.log(25 >= 30);
```

Expected output: `true`, `false`, `false`.

<Warning>`=` assigns a value; `===` compares values. JavaScript also has `==`, which performs type conversion. Use strict equality (`===`) in these exercises so a text value and a number are not treated as identical.</Warning>

## Choose a branch

```javascript
const studiedMinutes = 20;
const targetMinutes = 30;

if (studiedMinutes >= targetMinutes) {
  console.log("Target reached.");
} else if (studiedMinutes === 0) {
  console.log("Choose a short task to begin.");
} else {
  console.log(`Keep going: ${targetMinutes - studiedMinutes} minutes left.`);
}
```

The condition inside parentheses is checked first. If it is true, its brace-delimited block runs. Otherwise, the next condition is checked. The final `else` handles the remaining case. Only one branch in this chain runs.

For `20`, the message is `Keep going: 10 minutes left.` Try `0`, `30`, and `45` separately. The target branch must handle both exactly meeting the target and exceeding it.

## Combine boolean conditions

With boolean values, `&&` means both conditions must be true; `||` means at least one must be true; `!` reverses true and false.

```javascript
const hasRead = true;
const hasPractised = false;

console.log(hasRead && hasPractised);
console.log(hasRead || hasPractised);
console.log(!hasPractised);
```

Output: `false`, `true`, `true`. These operators also have behaviour involving non-boolean values; we will examine that later. For now, use explicit comparisons or booleans in conditions.
