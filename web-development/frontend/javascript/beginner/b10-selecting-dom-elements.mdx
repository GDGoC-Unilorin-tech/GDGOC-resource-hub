## Understand the idea

The Document Object Model (DOM) is the browser's tree of objects representing the page. `document.querySelector` returns the first matching element, or `null` if there is no match. Its argument uses CSS selector syntax: `#status` selects an id.

The DOM is not your original source file: JavaScript can change the in-memory page without rewriting the HTML on disk. Our deferred script runs after the HTML is parsed, so elements already exist when we select them.

## Run the example

```javascript
const status = document.querySelector("#status");
if (status !== null) {
  console.log(status.textContent);
}
console.log(document.querySelector("#missing"));
```

**Expected result:** The console shows `Waiting`, then `null`.
