## Understand the idea

A loop runs a block repeatedly. `for...of` assigns each array item to a loop variable in order. The block can read its properties or add to a running total. An empty array performs zero iterations, so an initial total of zero stays zero.

Initialise the accumulator before the loop. Placing it inside the loop resets it on every iteration. `break` can end a loop early and `continue` skips to its next iteration, but neither is needed for this total.

## Run the example

```javascript
const sessions = [{ minutes: 10 }, { minutes: 20 }];
let total = 0;
for (const session of sessions) {
  total = total + session.minutes;
}
console.log(total);
```

**Expected result:** The total is `30`. Replacing the array with `[]` prints `0`.

## Practice challenge

Write totalMinutes(sessions) that returns the sum of each object’s minutes. Call it with 5 and 15 minute sessions, then an empty array.

<Accordion title="Suggested solution: compare after trying">

Replace `app.js` with this complete solution and use the same HTML/setup above.

```javascript
function totalMinutes(sessions) {
  let total = 0;
  for (const session of sessions) {
    total = total + session.minutes;
  }
  return total;
}
console.log(totalMinutes([{ minutes: 5 }, { minutes: 15 }]));
console.log(totalMinutes([]));
```
