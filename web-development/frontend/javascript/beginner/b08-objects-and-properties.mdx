## Understand the idea

An object groups related values under property names. Unlike an array index, a property name describes what the value means. Object literals use braces and comma-separated `name: value` pairs. Dot notation reads a known property; brackets can read a property name stored in a variable.

Properties can hold strings, numbers, booleans, arrays, or other objects. A missing property reads as `undefined`. Adding a property or changing a property value mutates the existing object, even when its variable uses `const`.

## Run the example

```javascript
const project = { title: "Profile", category: "web", complete: false };
console.log(project.title);
project.complete = true;
const field = "category";
console.log(project[field]);
console.log(project.complete);
```

**Expected result:** Output is `Profile`, `web`, and `true`.
