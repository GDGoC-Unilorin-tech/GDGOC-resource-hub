## Understand the idea

Scope describes where a name can be used. Variables declared inside a function are local to that function. `let` and `const` are also limited to the brace-delimited block where they are declared. A function can read names in its surrounding scope, but explicit parameters usually make a calculation easier to reuse.

Do not rely on a variable with the same name elsewhere changing by accident. Two declarations in different scopes can refer to different values. Reading a function's local variable from outside causes a `ReferenceError`.

## Run the example

```javascript
const total = 100;
function addMinutes(first, second) {
  const total = first + second;
  return total;
}
console.log(addMinutes(5, 10));
console.log(total);
```

**Expected result:** The function result is `15`; the outer total remains `100`.

## Practice challenge
