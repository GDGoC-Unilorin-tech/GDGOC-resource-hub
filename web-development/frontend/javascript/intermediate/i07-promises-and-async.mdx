## Understand the idea

A promise represents a future outcome: pending, fulfilled, or rejected. `async` functions always return promises. `await` pauses the continuation of that async function until a promise settles; it does not freeze the whole browser.

Use try/catch around awaited work to handle rejection. Calling an async function without awaiting or otherwise handling its promise can lose the error. Our first example uses Promise.resolve and Promise.reject to practise outcomes without an external service.

## Run the example

```javascript
async function showTitle() {
  try {
    const title = await Promise.resolve("Profile");
    console.log(title);
  } catch (error) {
    console.log("Could not load title");
  }
}
showTitle();
console.log("Other work continues");
```

**Expected result:** Other work continues is printed before Profile, because the continuation after await runs later.
