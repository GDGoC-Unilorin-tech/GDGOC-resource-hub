## Understand the idea

`localStorage` stores strings for an origin, normally persisting across reloads. It is not a database for secrets, an account system, or proof of learning progress. Any same-origin script can read it; browser settings or quota limits can make access fail.

Use a specific key, validate values when reading, and wrap reads and writes in try/catch. Use the local HTTP setup in the next lesson for dependable origin behaviour; file-URL storage behaviour varies across browsers. Never clear all origin storage just to reset one preference: remove your own key only.

## Run the example

```javascript
const key = "gdgoc-js-category";
function readCategory() {
  try {
    const value = localStorage.getItem(key);
    return value === "web" ? value : "all";
  } catch (error) {
    return "all";
  }
}
console.log(readCategory());
```

**Expected result:** A missing, invalid, or inaccessible value falls back to all; a stored web value returns web.

## Practice challenge

Add saveCategory(value) that accepts only all or web, reports whether the write succeeded, and keeps the page usable on failure. Test saving web, reading it back, and passing invalid.

### Completion checklist

- [ ] With available storage, the output is true, web, false.
- [ ] A storage failure does not crash the script.
- [ ] I can remove only gdgoc-js-category in DevTools to reset it.

Return a boolean from the save function. Do not put the write outside try.

<Accordion title="Suggested solution: compare after trying">

Replace `app.js` with this complete solution and use the same HTML/setup above.

```javascript
const key = "gdgoc-js-category";
function saveCategory(value) {
  if (value !== "all" && value !== "web") return false;
  try {
    localStorage.setItem(key, value);
    return true;
  } catch (error) {
    return false;
  }
}
console.log(saveCategory("web"));
try {
  console.log(localStorage.getItem(key));
} catch (error) {
  console.log("Storage unavailable; keep using the page.");
}
console.log(saveCategory("invalid"));
```

Explain why it meets each checklist item. Different implementations can be correct.
