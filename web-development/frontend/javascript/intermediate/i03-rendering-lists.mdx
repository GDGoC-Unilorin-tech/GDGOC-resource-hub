## Understand the idea

`createElement` creates a disconnected element. Set its text, then `append` it to a parent. `replaceChildren` removes old children and can insert replacements. Clearing the list once at the start of rendering prevents repeated renders from duplicating entries.

A render function should describe the current data, not keep appending history. Use `textContent` for data strings. A status region can communicate a result count, but keep updates meaningful rather than announcing every tiny change.

## Run the example

```javascript
function render(projects) {
  const list = document.querySelector("#projects");
  list.replaceChildren();
  for (const project of projects) {
    const item = document.createElement("li");
    item.textContent = project.title;
    list.append(item);
  }
  document.querySelector("#status").textContent = `${projects.length} projects`;
}
render([{ title: "Profile" }, { title: "Study planner" }]);
```

**Expected result:** Two list items appear, and status reads 2 projects.

function render(projects) {
