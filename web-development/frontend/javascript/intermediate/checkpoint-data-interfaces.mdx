## Task

Create an array of three project records in two categories. Derive matching records with filter, copy before sorting by a numeric duration, and render a list using DOM element creation. Include a count and empty message.

Attempt the task without copying a full implementation. Refer back to individual lesson concepts when necessary. Keep this work in a separate practice folder.

## Completion criteria

- [ ] Web selection shows only its records in ascending duration.
- [ ] A category with no records gives a clear empty message.
- [ ] Calling render twice does not duplicate items.
- [ ] Original order is unchanged and title markup stays literal text.

## Evidence to keep

Keep your source files and a short record of each input/action, expected result, actual result, and repair. Explain one design choice and one error you investigated. A screenshot supports the record but does not replace runnable code.

<Accordion title="Hint">

Build the selected array first, then render it. Clear old children before appending new ones.

</Accordion>
