## Understand the idea

`map` calls a callback for each item and collects its return values into a new array. `filter` keeps items whose callback returns a truthy value. Neither method itself changes the original array, though a callback that mutates an object can still change shared objects.

An arrow function is another function syntax. `item => item.title` has one parameter and implicitly returns an expression. With braces, write `return` explicitly. `includes` checks for a substring; `toLowerCase` makes a lowercase copy for simple case-insensitive matching.

## Run the example

```javascript
const projects = [{ title: "Profile", category: "web" }, { title: "Poster", category: "design" }];
const web = projects.filter(project => project.category === "web");
const titles = web.map(project => project.title);
console.log(titles.join(", "));
console.log(projects.length);
```

**Expected result:** The output is Profile and 2. join combines array strings with a separator.

const projects = [{ title: "Profile" }, { title: "Poster" }];
function searchTitles(query) {
  const matches = projects.filter(project => project.title.toLowerCase().includes(query.toLowerCase()));
  return matches.length === 0 ? "No matches" : matches.map(project => project.title).join(", ");
}
