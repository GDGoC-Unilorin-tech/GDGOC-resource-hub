## Understand the idea

`sort` rearranges the array it is called on. Make a new array with spread (`[...items]`) when you need the original order. A comparator returns a negative number to place the first item earlier, positive to place it later, or zero for equal ordering. Numeric sorting needs a comparator.

Object spread (`{...item}`) copies its own enumerable properties into a new object. This is shallow: nested objects are still shared. A property written after the spread overrides the copied property.

## Run the example

```javascript
const durations = [20, 5, 100];
const sorted = [...durations].sort((a, b) => a - b);
console.log(sorted.join(", "));
console.log(durations.join(", "));
const oldProject = { title: "Profile", complete: false };
const updated = { ...oldProject, complete: true };
console.log(oldProject.complete);
console.log(updated.complete);
```

**Expected result:** Output is 5, 20, 100; then 20, 5, 100; then false and true.
