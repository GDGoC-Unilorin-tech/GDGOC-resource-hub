## Prerequisites and outcomes

Complete Beginner language foundations, functions, collections, DOM updates, and events first. You will then learn to transform data, handle form input, preserve a preference, and show clear loading, empty, success, and error states.

| Module | Planned topics | Practical checkpoint |
| --- | --- | --- |
| Data-driven interfaces | Array iteration methods; object updates; rendering lists with DOM APIs; filtering and sorting without unexpected mutation | Render and filter portfolio projects |
| Forms and saved preferences | Submit events; numeric conversion; input checks; accessible error messages; JSON; localStorage and failure handling | Save a non-sensitive display preference and recover from missing/invalid stored data |
| Asynchronous JavaScript | Callbacks; promises; async/await; fetch; HTTP status checks; loading, empty, and error states | Load a local JSON file and recover from a failed request |

## Intermediate portfolio milestone — planned

Extend the Beginner project filter into a searchable project explorer. Load sample project data from a local JSON file and remember a display preference. The lessons will explain how to use a local HTTP server before introducing fetch; opening a file directly is not sufficient for every browser API.

No paid API or secret key should be required. Full project instructions, hints, checklist, and a suggested solution will be published with this level.
