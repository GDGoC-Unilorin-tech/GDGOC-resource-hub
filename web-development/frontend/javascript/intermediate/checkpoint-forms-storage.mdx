## Task

Build a labelled numeric input for a whole-number target from 1 to 120. Handle form submission, validate and display the target, and save it under one named localStorage key. On load, parse and validate saved data; fall back to 30 when data is missing, malformed, or unavailable.

Attempt the task without copying a full implementation. Refer back to individual lesson concepts when necessary. Keep this work in a separate practice folder.

## Completion criteria

- [ ] Blank, 0, 121, and fractions do not update the target.
- [ ] A valid 45 survives refresh when storage is available.
- [ ] Malformed JSON and a saved null do not crash the page.
- [ ] Storage failure leaves the current target usable and produces truthful feedback.

## Evidence to keep

Keep your source files and a short record of each input/action, expected result, actual result, and repair. Explain one design choice and one error you investigated. A screenshot supports the record but does not replace runnable code.

<Accordion title="Hint">

Treat stored data as input too. Wrap both reading/parsing and writing in try/catch.

</Accordion>
