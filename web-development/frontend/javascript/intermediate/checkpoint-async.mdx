## Task

Use a local HTTP server and projects.json. Build a Load button and result list with a persistent status region. Handle HTTP failures, parsing failures, and invalid records, and make retry possible.

Attempt the task without copying a full implementation. Refer back to individual lesson concepts when necessary. Keep this work in a separate practice folder.

## Completion criteria

- [ ] Valid data produces the expected titles.
- [ ] [] is a successful empty state, not an error.
- [ ] A missing file and [null] produce useful error messages.
- [ ] Restoring valid data and retrying recovers.
- [ ] The load action is restored in every outcome.

## Evidence to keep

Keep your source files and a short record of each input/action, expected result, actual result, and repair. Explain one design choice and one error you investigated. A screenshot supports the record but does not replace runnable code.
