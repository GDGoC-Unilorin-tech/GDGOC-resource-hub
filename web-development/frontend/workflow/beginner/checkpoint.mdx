## Demonstrate your skills

Explain the difference between a modified file, staged change, local commit, and pushed branch. Demonstrate a focused README change and show exactly what a reviewer would receive.

## Evidence checklist

- [ ] I demonstrated the behaviour rather than only describing it.
- [ ] I recorded the environment and exact steps.
- [ ] I distinguished passed, failed, and untested checks.
- [ ] I explained a limitation and a next action.

<Accordion title="Hint">
Use a small example and known inputs. Explain what the tool revealed and how that changed your next action.
</Accordion>

<Accordion title="Suggested assessment">
The reviewer can start the site, identify the intended change, and distinguish local commits from remote review. A reviewer should be able to repeat the steps. If you cannot reproduce a result, mark this checkpoint Needs practice and revisit the relevant lesson; there is no automatic lock.
</Accordion>
