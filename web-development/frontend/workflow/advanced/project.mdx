## Project brief

Add regression checks and complete a keyboard/layout review. Build a public release folder, test it locally, and request peer review. Use your own Firebase project for a preview and live release when account access is available; otherwise label the cloud milestone incomplete.

## Acceptance criteria

Automated checks and the manual record agree; only intended files enter public; another learner can reproduce setup and understand release status.

## Build and review

1. Write the expected outcome before editing.
2. Work in your practice repository on a focused branch.
3. Inspect changes, run the relevant checks, and commit a coherent result.
4. Ask a peer to follow the record; capture their feedback and your retest.

## Completion checklist

- [ ] I met each acceptance criterion or recorded what remains incomplete.
- [ ] My files and written setup instructions agree.
- [ ] My test record contains actual results.
- [ ] I can explain the change without reading the solution.
