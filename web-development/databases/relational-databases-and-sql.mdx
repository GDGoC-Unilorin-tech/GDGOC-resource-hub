## Planned skill courses

Each skill course will provide an overview explaining what you will learn, the tools you need, and how to complete the course.

1. **Beginner:** Topic lessons, then a project and completion checklist.
2. **Intermediate:** Deeper lessons, then a project and completion checklist.
3. **Advanced:** Advanced work within the same skill, then a project and completion checklist.
4. **Final building challenge:** Brief, requirements, optional hints, completion checklist, and separate suggested solution.
5. **Further learning and references:** Optional external links with descriptions, at the end of the course.

Each topic will include objectives, prerequisites, explanations, code examples, and a practical challenge with concrete instructions, expected outcomes, completion criteria, optional hints, and a separate suggested solution. Guided progression will use visible checklists. Stages are not locked; saved progress and automatic assessment are not implemented.
